# TeamNext — motions, canonical

One motion token from `src/lib/mudavym/motion.ts`. A schedule under
construction is a working document; the only thing that should ever draw the
eye is a day that has a problem.

| id | token | curve · ms | fires |
|---|---|---|---|
| `tm-ink` | `ink` | HOUSE · 160ms | day-chip border state and control hover/focus — colour only, nothing translates |

Deliberate non-motions: gap rows do not animate in (an unfilled shift is not
an arrival, it is a standing fact); the labour figure does not tally (it is a
sum of record that changes only when a shift changes); "assigned" and
"requested" confirmations appear in place — the change of words is the event.
