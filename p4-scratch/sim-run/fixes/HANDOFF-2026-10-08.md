## 10. Tools and exact recipes

All live in `fixes/tools/`. Run these from `/Users/aldemirkonuk/Projects` unless noted.

- **Re-sync a lane onto main:** `bash p4-scratch/sim-run/fixes/tools/merge_main.sh /Users/aldemirkonuk/Projects/wt-fix-<lane>`. It auto-resolves only README rows and `sql_outside_migrations.txt`; anything else prints `CONFLICT (manual)`.
- **Six guards, file count and ownership:** `bash p4-scratch/sim-run/fixes/tools/lanecheck.sh wt-fix-<lane>`. It must stay ≤15 files with `ownership []`. **It does not run claims.**
- **Claims:** one lane at a time, from inside the worktree: `PATH=/usr/local/bin:$PATH bash scripts/check_decision_claims.sh` (it needs python 3.11).
- **Typecheck:** `cd wt-fix-<lane>/apps/api-gateway && npx tsc --noEmit -p tsconfig.json` and `-p tsconfig.spec.json`. Only the two `@simplewebauthn` errors are known. For web: `cd apps/web && npx tsc --noEmit`. Gateway jest does not typecheck (memory `gateway-jest-does-not-typecheck`).
- **Local SQL tests:** `pgtest.sh` (memory `local-postgres-from-migrations`).
- **Audit (ADR 0090, three roles):** `Workflow` with `scriptPath: /Users/aldemirkonuk/Projects/p4-scratch/sim-run/fixes/audit.js` and args `{"prs":[{"n":611,"lane":"recregisters","sha40":"<full sha>","wt":"/Users/aldemirkonuk/Projects/wt-fix-recregisters","prior":{"sha":"ada37ebb1…","verdict":"PASS","report":"fixes/audits/611-ada37ebb1/report.md","why":"re-sync onto be9a16ccf"}}]}`.
  - Use one PR per workflow.
  - The bundle step refuses if CI is not green or an owned file is touched.
- **When the audit's post step fails or is killed:**
  1. `python3 p4-scratch/sim-run/fixes/tools/assemble_report.py <journal-dir> <pr> <sha40> <PASS|BLOCK> p4-scratch/sim-run/fixes/audits/<pr>-<sha9>/report.md`
  2. Fix the Limitations line so it says why.
  3. `gh pr comment <pr> -R aldemirkonuk/RestaurantAIAutomation --body-file <report>`
- **Merge:** `gh pr merge N --squash --match-head-commit <sha40> --subject "<title> (#N)" --body-file p4-scratch/sim-run/fixes/pr/<lane>.squash.md`. Then `bash p4-scratch/sim-run/fixes/tools/deploy_check.sh <needle|->`, which greps the Vercel bundle and the gateway boot SHA.
- **`gh`** needs a repo cwd or `-R aldemirkonuk/RestaurantAIAutomation`.
- **Shell quirks:**
  - zsh: quote jq expressions that contain brackets; wrap loops in `bash -c`.
  - There is no `timeout` binary.
  - `/tmp/..` resolves to `/private`.
- **Durability:** nothing you need tomorrow goes in the scratchpad; write it to `p4-scratch/<lane>/`. After any new head, pin it with `git update-ref refs/rescue/<date>/<session8>-<lane> <sha>`.
