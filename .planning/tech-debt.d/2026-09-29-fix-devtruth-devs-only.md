## /dev/truth opened for any signed-in user and its gateway read any house's row counts — CLOSED on `fix/devtruth-devs-only` — 2026-09-29

Found by the PR #514 audit (`origin/main-1ll9rp:.planning/07-reference/pr-audits/514-19df181.md:14,23-24`); founder answer 2026-09-29, verbatim: "Devs only (Recommended)" and "only devs can open it" (bracket in ADR 0143 §5).

**What.** `/dev/truth` (`apps/web/src/App.tsx`) sat inside the signed-in shell with no role gate, so any owner, manager or staff member who typed the URL opened it. Its gateway routes (`apps/api-gateway/src/analytics/dev-truth.controller.ts`, `GET /analytics/dev/{reach,swallow,asof}/:restaurantId`) carried only `JwtAuthGuard` and a production 404. The page also put `?tab=` and `?r=` into the request path unchecked. **Correction to the audit:** it said the controller had "no tenant check". `JwtAuthGuard` already runs `assertTenantMatch` over path params (`jwt-auth.guard.ts`, `assert-tenant-match.ts`), so a foreign `:restaurantId` was refused before this change as well. What was missing was a check the controller owns and a spec that pins it.

**Fix.** Web: the route is wrapped in `ProtectedRoute requiredStudioRole={['developer']}` (`DEV_TRUTH_STUDIO_ROLES` in `DevTruth.tsx`), the Studio role `/studio/queue` and `/studio/certify` already gate on. `?tab=` is checked against the three known tabs (anything else falls back to `reach`), and `r` is `encodeURIComponent`-ed into one path segment. Gateway: every route runs, in this order, the production 404 (for everybody), then `PlatformOperatorService.isDeveloper` (a new method: the `user_roles` `developer` read `isOperator` already did, without the operator grant, failing closed with 503) returning 403 for a non-developer before anything is read, then `assertTenantMatch` against the session's house. `AnalyticsModule` provides `PlatformOperatorService`; `liveness.route.spec.ts` boots `AppModule` green. Tests: `dev-truth.controller.spec.ts` (8, 7 red on `origin/main`), `platform-operator.service.spec.ts` (+7), `apps/web/src/__tests__/DevTruth.access.test.tsx` (7, all red on `origin/main`; tab and `r` cases mutation-checked red against the old two lines). CLAIMS `DEVTRUTH-DEVS-ONLY` (`resolved`, static).

**Not done.** No browser or live-gateway run: the gate was checked by component tests and a controller spec, not a signed-in session. `/dev-sandbox` stays on its owner/manager gate (see the ADR 0143 bracket).
