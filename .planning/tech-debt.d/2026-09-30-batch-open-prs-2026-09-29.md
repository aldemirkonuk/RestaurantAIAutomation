## The deploy own-run guard does not pin how ci-gate executes — OPEN — 2026-09-30

Filed from the ADR 0090 audit of #534 (rounds 3 and 4, Opus planner), on the founder's pick, verbatim: *"Honest record (Recommended)"*. `scripts/check_deploy_own_pushes.py` (gate-owned) holds `deploy.yml` to this repository's own CI runs on main, a push or a manual run (ADR 0097, 2026-09-30 amendment). It pins the refusal step's text and each job's `if`, and its self-test plants 52 breaks.

It does not pin how `ci-gate` executes. Any of the following can turn `ci-gate` green on a foreign or non-push run without the guard noticing:
- a job-level key other than `if`;
- another step or action before the refusal step;
- a write to the runner's env or path files other than the literal `GITHUB_ENV` or `GITHUB_OUTPUT`;
- a column-0 comment inside `on:`, which hides a trigger added after it.

**Known examples.** Each of these passes the guard at this writing:
- `concurrency: |` placed before the refusal step, which turns the following steps into a string;
- `container:`, `runs-on: self-hosted` or `services:` on `ci-gate`;
- a job-level `env: BASH_ENV` on `ci-gate`;
- a `uses: actions/github-script` step before the refusal step that exports `BASH_ENV`;
- a `GITHUB_PATH` write, or an indirect write to the env file (for example, a path computed from `printenv`);
- a column-0 comment inside `on:` followed by an added trigger.

**Why runtime still holds.** Every stage's and `deploy-audit`'s job-level `if` independently requires the own-run group, and the guard pins those `if`s exactly. None of the examples changes a job `if`. Each also needs an edit to `deploy.yml`, which is gate-owned and so faces an ADR 0090 audit and the founder's sign-off.

**The fix.**
- Pin `ci-gate` whole: its job-level keys, its step list in order (an unbroken `steps:` sequence, no `uses:` step), and no write to `$GITHUB_*` files.
- Read comment lines as part of `on:`.
- Plant each example in the self-test.
- Then update ADR 0097's "Not held", the claim `DEPLOY-RUNS-ONLY-ON-OWN-PUSHES`, and this entry.

**Severity:** low while open. This is defence in depth; the stage `if`s carry the protection.
