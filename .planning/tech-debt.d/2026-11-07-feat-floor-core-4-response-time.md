## The response-time port's caller owes these before its figures go to managers — OPEN — 2026-11-07

Found by the ADR 0090 session audit of PR #768 (`packages/floor-core/src/response-time.ts`). `responseSamples` has no caller yet; these fall to the floor gateway that builds `SeatingFacts`, and to the report that ranks waiters (ADR 0346).

1. **Pass null, never `""`.** `caretakerAtSeatId ?? curr.actorId` keeps `""`, and a falsy id is dropped from every waiter's figure without a trace. The uuid columns cannot produce `""`; a caller that builds facts from anything else must normalise. The package keys on `seatingId` alone, so the caller also scopes events and facts to one house.
2. **A table with no caretaker at seat time** (none assigned, cleared as absent under ADR 0351 `:23`, or `caretaker_at_seat_id` set null by `ON DELETE SET NULL` in the floor's record migration) leaves its open greeting gap out of every waiter's figure; past T, it counts for the table only, and only when the table is not hidden. The board and report should show such seatings as uncovered rather than let the silence vanish.
3. **Credit follows the visit.** A colleague's or manager's check-in carries the open gap after it (the handoff rule), bounded by the caretaker's last tap; with a caretaker, anyone's first check-in closes the caretaker's greeting gap, so a colleague's tap can end it early; and with no caretaker, the first visitor, a manager who seated included, takes the greeting gap. The report decides whether manager ids appear in waiter rankings. Who may mark someone absent is an input to these figures too (ADR 0351 `:29`).
4. **Pass every field the facts promise.** `tableHidden` must be an explicit `false` for a shown table: a missing flag reads as hidden and keeps the table out of the per-table figures (its gaps stay in the waiter's, F7). `caretakerLastTapAt` is the caretaker's last tap on any table that service day, not on this one. An undone Paid (ADR 0353 `:43`) is passed as null.
5. **Show what was not measured.** The report surfaces `seatingsWithoutFacts`, `seatingsWithoutAnchor` and `seatingsNotClosed`, so a seating left out of a figure is listed, not silent.

These are executor's readings under OD-242 (the header's readings paragraph); ADR 0346 `:64` names only who must not get the greeting gap.
