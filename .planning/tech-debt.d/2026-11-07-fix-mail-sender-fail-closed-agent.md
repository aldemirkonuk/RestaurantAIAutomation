## EmailParsingAgent files a letter under an order by thread headers before it looks at the sender — OPEN — 2026-11-07

**What is true (read from the code, not run).** `EmailParsingAgent._process_inbound_email` matches a letter to an order by `gmail_thread_id`, then by `In-Reply-To` / `References`, and only then looks up the provider from the sender. A letter from any address that carries the Message-ID of one of the house's outbound letters in `In-Reply-To` is filed under that order. The provider lookup then uses the real sender, so the row's `provider_id` is not the vendor's, but the letter still sits in the order's thread. The gateway bridge was not checked for the same pattern. **What closes it.** A thread match should count only when the sender is the order's vendor (or a person the house added to that thread). Otherwise the letter is held for a person, the same as an unauthenticated letter above.
