## Root Cause

TypeScript 5.9.3 (resolved via `^5.3.3` semver) and `@types/react@18.3.x` (installed globally for react@18.3.1 dependencies) were bleeding into the `apps/web` TypeScript compilation. The `react-router-dom@6.30.3` types use `React.ReactElement` which was being resolved against `@types/react@18.3.27` (from the pnpm store, used by peer packages) while `apps/web` expects `@types/react@18.2.x`. The newer `@types/react@18.3` changed `ReactNode` strictness, causing `ReactElement<unknown, ...>` to be incompatible — triggering **1849 TS2786 errors** across 133 source files.
