# Phase 27 — Plan 02: Backend — Vendor Catalogue API + Providers CRUD + Order Guard

## Objective
Build the NestJS `VendorCatalogueModule` with search/detail endpoints, update the Providers endpoints to
accept catalogue-based or custom vendor creation (auto-filling details from catalogue), and add an order
creation guard that blocks requests when a restaurant has no vendors.

## Tasks

### Task 1: VendorCatalogueModule scaffold
Create `apps/api-gateway/src/vendor-catalogue/` directory with:
- `vendor-catalogue.module.ts`
- `vendor-catalogue.service.ts`
- `vendor-catalogue.controller.ts`
- `dto/search-vendors.dto.ts`

### Task 2: Search endpoint
`GET /api/v1/vendor-catalogue/search`

Query params (via `SearchVendorsDto`):
- `q: string` — search term (name, specialties)
- `country?: string` — filter by country (default 'US')
- `type?: string` — filter by vendor type
- `limit?: number` — default 20, max 50
- `offset?: number` — default 0

Implementation:
```typescript
// In VendorCatalogueService.search()
const { data } = await this.supabase
  .from('vendor_catalogue')
  .select('*')
  .ilike('name', `%${q}%`)
  .eq('country', country ?? 'US')
  .eq('is_active', true)
  .range(offset, offset + limit - 1)
  .order('name');
```

### Task 3: Detail endpoint
`GET /api/v1/vendor-catalogue/:id` — returns full single vendor row

### Task 4: Update ProvidersService.create()
`POST /api/v1/providers` — extends existing endpoint to support two modes:

**Mode A — From Catalogue** (`catalogue_vendor_id` provided):
1. Fetch vendor from `vendor_catalogue` by ID
2. Copy all fields into the new `providers` row (name, type, phone, email, website)
3. Set `is_custom = false`, `catalogue_vendor_id = id`

**Mode B — Custom** (no `catalogue_vendor_id`):
1. Create providers row with user-supplied fields
2. Set `is_custom = true`, `catalogue_vendor_id = null`

```typescript
// Updated CreateProviderDto
class CreateProviderDto {
  catalogue_vendor_id?: string; // UUID — if present, auto-fill from catalogue
  name?: string;                // required if no catalogue_vendor_id
  type?: string;
  phone?: string;
  email?: string;
  website?: string;
  notes?: string;
  contact_name?: string;
}
```

### Task 5: Order creation guard
In the existing orders creation handler (or as a NestJS Guard):

```typescript
// Before creating an order, check provider count
const { count } = await this.supabase
  .from('providers')
  .select('*', { count: 'exact', head: true })
  .eq('restaurant_id', restaurantId)
  .eq('is_active', true);

if (count === 0) {
  throw new ForbiddenException({
    reason: 'no_vendors',
    message: 'You must add at least one vendor before placing orders.',
    redirect: '/providers',
  });
}
```

### Task 6: Register VendorCatalogueModule in AppModule
Add to `imports` array in `app.module.ts`.
