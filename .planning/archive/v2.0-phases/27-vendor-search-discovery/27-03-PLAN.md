# Phase 27 — Plan 03: Frontend — Providers Empty State + VendorSearchModal + Catalogue Browsing

## Objective
Redesign the Providers page to show a search-first empty state when no vendors exist, and build the
VendorSearchModal component that lets users search the catalogue and add vendors in one click.

## Tasks

### Task 1: services/api/vendors.ts
Create a dedicated API service file:
```typescript
export async function searchVendorCatalogue(q: string, country?: string): Promise<VendorCatalogueEntry[]>
export async function getVendorCatalogueEntry(id: string): Promise<VendorCatalogueEntry>
export async function addProviderFromCatalogue(catalogueVendorId: string): Promise<Provider>
export async function addCustomProvider(data: CustomProviderData): Promise<Provider>
```

### Task 2: VendorCatalogueCard component
`apps/web/src/components/providers/VendorCatalogueCard.tsx`

Displays:
- Vendor name (bold, large)
- Type badge (e.g. "Distributor" in wine-themed color)
- Location: city, state, country (if available)
- Wine specialties (small gray text, truncated at 2 lines)
- Phone / website icons (clickable)
- "Add to My Providers" button (primary wine-colored)

Design: clean card with subtle border, hover shadow, 
consistent with existing WineOps card components.

### Task 3: VendorSearchModal component
`apps/web/src/components/providers/VendorSearchModal.tsx`

Structure:
```
┌─────────────────────────────────────────────────────────┐
│  Find a Wine Vendor                              [×]    │
│                                                         │
│  🔍 Search vendors...          [country filter ▾]       │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │ Southern Glazers Wine & Spirits        Distributor│  │
│  │ Miami, FL · Bordeaux, Champagne, Napa            │  │
│  │                          [Add to My Providers]   │  │
│  └─────────────────────────────────────────────────┘   │
│  ┌───────────────────── ...more results ────────────┐   │
│                                                         │
│  Can't find your vendor?  Add Custom Vendor Instead →  │
└─────────────────────────────────────────────────────────┘
```

Behavior:
- Debounce 300ms on search input
- Empty state: "Search for a vendor by name or specialty"
- Loading state: skeleton cards (3 rows)
- No results: "No vendors found. Add a custom vendor instead."
- Success: toast "Added [Vendor Name] to your providers"
- Uses `AnimatePresence` for result list transitions
- Full-screen on mobile, max-w-2xl centered modal on desktop
- Uses existing Radix Dialog primitive
