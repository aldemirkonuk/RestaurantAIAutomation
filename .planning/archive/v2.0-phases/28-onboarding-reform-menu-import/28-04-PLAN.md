# Phase 28 — Plan 04: Frontend — Dashboard ActivationChecklist Component

## Objective
Build the persistent activation checklist that lives on the dashboard until all 3 setup tasks
are completed, giving users a clear and friendly guide to getting the most out of WineOps.

## Tasks

### Task 1: useOnboardingProgress hook
`apps/web/src/hooks/queries/useOnboardingProgress.ts`

```typescript
export function useOnboardingProgress() {
  const query = useQuery({
    queryKey: ['onboarding-progress'],
    queryFn: getOnboardingProgress,
    staleTime: 30_000, // refetch every 30s when window is focused
  })
  const mutation = useMutation({ mutationFn: updateOnboardingProgress })
  return { progress: query.data, isLoading: query.isLoading, update: mutation.mutate }
}
```

Visual details:
- Wine-red left border accent (4px)
- Completed tasks: green check circle + line-through gray text
- Incomplete tasks: empty circle with subtle animation on hover
- CTA buttons are small, secondary-styled — not intrusive
- Dismiss (✕) hides for the session only — reappears on next login until complete
- Uses `AnimatePresence` to slide out when all tasks are done
- Background: subtle white card with wine-50 tint border

### Task 3: Automatic progress updates on backend
In `auth.service.ts` / `providers.service.ts` / invitation flows:

**vendor_added**: When `POST /api/v1/providers` succeeds for a restaurant with previously zero providers:
```typescript
await this.supabase
  .from('user_onboarding_progress')
  .update({ vendor_added: true })
  .eq('restaurant_id', restaurantId);
```

**team_member_invited**: When `POST /api/v1/auth/invite` creates a new invite:
```typescript
await this.supabase
  .from('user_onboarding_progress')
  .update({ team_member_invited: true })
  .eq('restaurant_id', restaurantId);
```

**completed_at**: Set when all three booleans are TRUE:
```typescript
const { menu_uploaded, vendor_added, team_member_invited } = updatedRow;
if (menu_uploaded && vendor_added && team_member_invited) {
  await this.supabase
    .from('user_onboarding_progress')
    .update({ completed_at: new Date().toISOString() })
    .eq('restaurant_id', restaurantId);
}
```

### Task 4: Wire ActivationChecklist into Dashboard.tsx

```tsx
// In Dashboard.tsx, above the main grid:
const { progress } = useOnboardingProgress()
const showChecklist = progress && !progress.completed_at

{showChecklist && (
  <ActivationChecklist progress={progress} />
)}
```

## Verification
- [ ] New user logs in → checklist appears with all 3 tasks incomplete
- [ ] Navigate to /get-started → upload menu → return to dashboard → ① shows as complete
- [ ] Add a vendor → ② shows as complete (after page refresh or re-fetch)
- [ ] Send a team invite → ③ shows as complete
- [ ] All 3 complete → checklist animates away
- [ ] Existing users with completed onboarding → checklist never appears
