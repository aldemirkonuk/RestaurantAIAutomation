# Plan 18-04: Console JSON Logging Gap Closure

## Gap
UAT Test 7 found that stdout (console handler) emits plain-text logs, not JSON.
Only `logs/agent-orchestrator.log` (file handler) emits structured JSON.
ROADMAP INFRA-03 criterion: "All agent logs emit structured JSON."

## Fix
Add `LOG_JSON_STDOUT` env var to `setup_logger` in `utils/logger.py`.
When `LOG_JSON_STDOUT=1`, console handler uses `AgentJsonFormatter` instead of plain-text formatter.
Default remains human-readable (dev UX unchanged).

## Task

**Task 1:** Patch `services/agent-orchestrator/utils/logger.py`
- Add `import os` 
- In `setup_logger`, after creating `console_handler`, check `os.environ.get("LOG_JSON_STDOUT")`
- If truthy: set `AgentJsonFormatter` on console handler
- Else: keep existing plain-text formatter
- Update module docstring to reflect dual-mode behavior

## Success Criteria
- `LOG_JSON_STDOUT=1 python -c "from utils.logger import setup_logger; l=setup_logger('test'); l.info('hi')"` emits valid JSON on stdout
- Without `LOG_JSON_STDOUT`, stdout remains human-readable plain text
- File handler behavior unchanged
