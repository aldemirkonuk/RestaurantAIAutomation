// onModuleInit() reads these three env vars — ALL THREE must be present
async onModuleInit() {
  const clientId = this.configService.get<string>('GMAIL_CLIENT_ID');
  const clientSecret = this.configService.get<string>('GMAIL_CLIENT_SECRET');
  const refreshToken = this.configService.get<string>('GMAIL_REFRESH_TOKEN');
  this.senderEmail = this.configService.get<string>('GMAIL_SENDER_EMAIL') || 'notifications@wineops.ai';

  if (!clientId || !clientSecret || !refreshToken) {
    this.logger.warn('Gmail credentials not configured. Email sending will be mocked.');
    return;
  }
  // Stores credentials for lazy-init on first send:
  this.gmailCredentials = { clientId, clientSecret, refreshToken };
  this.logger.log('Gmail API deferred — will initialize on first send (fast startup).');
}

**File 1: `scripts/gmail-setup/generate_refresh_token.py`**

Python script using `google-auth-oauthlib` InstalledAppFlow. The script:
- Imports `google_auth_oauthlib.flow.InstalledAppFlow`
- Defines SCOPES = ['https://www.googleapis.com/auth/gmail.send', 'https://www.googleapis.com/auth/gmail.readonly']
- Accepts `--client-secrets` argument (path to client_secrets.json downloaded from Google Cloud Console)
- Runs `InstalledAppFlow.from_client_secrets_file(secrets_file, SCOPES).run_local_server(port=0)`
- Prints the refresh_token with clear "=== GMAIL_REFRESH_TOKEN ===" delimiters
- Prints next-step instructions (copy to Railway → GMAIL_REFRESH_TOKEN)
- Prints a local install command at top of script as a comment: `# pip install google-auth-oauthlib`
- Catches ImportError and prints install command if library not installed

Markdown guide with these exact sections:

## Prerequisites
- `wineops.ai@gmail.com` Google account must exist before these steps
- If it doesn't exist: create at accounts.google.com. Use a strong password. This is a program account — enable recovery options.

## Step 1: Create Google Cloud Project
1. Go to https://console.cloud.google.com
2. Click "Select a project" → "New Project"
3. Name: "WineOps AI" | Click "Create"
4. Note your Project ID (e.g. `wineops-ai-123456`) — needed for Pub/Sub topic name in Plan 05

## Step 2: Enable Gmail API
1. APIs & Services → Library → search "Gmail API" → Click "Gmail API" → "Enable"
2. Confirm status shows "Enabled" with green check

## Step 3: Configure OAuth Consent Screen
1. APIs & Services → OAuth consent screen
2. User Type: **External** (select External, not Internal — wineops.ai is not a Google Workspace account)
3. App name: "WineOps AI"
4. User support email: your personal email
5. Developer contact: your personal email
6. Scopes → Add or Remove Scopes → manually enter:
   - `https://www.googleapis.com/auth/gmail.send`
   - `https://www.googleapis.com/auth/gmail.readonly`
7. Test users → Add Users → add `wineops.ai@gmail.com`
8. Save and Continue through all steps

## Step 4: Create OAuth2 Credentials
1. APIs & Services → Credentials → "Create Credentials" → "OAuth 2.0 Client ID"
2. Application type: **Web application** (NOT Desktop — server refresh token flow requires Web application)
3. Name: "WineOps Railway Server"
4. Authorized redirect URIs → Add URI: `https://developers.google.com/oauthplayground`
5. Click "Create"
6. Download JSON → save as `client_secrets.json` (DO NOT commit this file to git)
7. Note: `client_id` → this is GMAIL_CLIENT_ID; `client_secret` → this is GMAIL_CLIENT_SECRET

## Step 5: Generate Refresh Token (Two Methods)

### Method A: Python script (recommended)
```bash
pip install google-auth-oauthlib
python scripts/gmail-setup/generate_refresh_token.py --client-secrets /path/to/client_secrets.json
```
- Browser opens → sign in as wineops.ai@gmail.com → Allow
- Copy the printed GMAIL_REFRESH_TOKEN value

### Method B: OAuth Playground (no Python required)
1. Go to https://developers.google.com/oauthplayground
2. Click gear icon → check "Use your own OAuth credentials"
3. Enter GMAIL_CLIENT_ID and GMAIL_CLIENT_SECRET
4. Step 1 input box: paste `https://www.googleapis.com/auth/gmail.send https://www.googleapis.com/auth/gmail.readonly`
5. Click "Authorize APIs" → sign in as wineops.ai@gmail.com → Allow
6. Step 2: Click "Exchange authorization code for tokens"
7. Copy the `refresh_token` value — this is GMAIL_REFRESH_TOKEN

## ⚠️ Security Notes
- NEVER commit `client_secrets.json` to git (add to .gitignore)
- NEVER put GMAIL_CLIENT_ID, GMAIL_CLIENT_SECRET, or GMAIL_REFRESH_TOKEN in code files
- Store ALL credentials exclusively in Railway dashboard environment variables
- The refresh_token does not expire as long as it is used at least once every 6 months

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01-01 | Information Disclosure | client_secrets.json on disk | mitigate | Add `client_secrets.json` to `.gitignore` in Task 1; GOOGLE_CLOUD_SETUP.md explicitly warns never to commit |
