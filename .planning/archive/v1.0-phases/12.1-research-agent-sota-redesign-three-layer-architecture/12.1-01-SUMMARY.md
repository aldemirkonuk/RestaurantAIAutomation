### Task 2 — research_agent_helpers.py (+365 lines)

Six new sections appended after `build_citation_record`:

**Section 6 — `BoundedLRUCache` class (Bug #10 fix)**
- Thread-safe bounded LRU using `OrderedDict` with `move_to_end`
- `max_size` enforced on every `put()` via `popitem(last=False)`
- TTL support on `get()` — stale entries auto-evicted
- Plan 03 will use this to replace the unbounded `_url_cache: dict` in `research_tasks.py`

**Section 3 — Entity Cache Helpers (D-04)**
- `_cache_key_wine(name, vintage, producer)` — SHA-256 hash, `research:wine:` prefix
- `_cache_key_producer(producer)` — alphanumeric normalized, `research:producer:` prefix
- `_cache_key_region(region_or_appellation)` — alphanumeric normalized, `research:region:` prefix (D-04 Tier 3)
- `get_entity_cache(key, redis_client)` — Redis-first, `_memory_cache` fallback
- `put_entity_cache(key, value, ttl_days, redis_client)` — writes to both; evicts oldest when `> _MEMORY_CACHE_MAX`

**Section 1 — `run_layer1_inference()` (D-01, D-08)**
- Zero-cost deterministic fills from Phase 9 ontology
- **Appellation → grape_variety:** only when `required_grapes` has exactly 1 entry with `min_pct==100`
- **Appellation → country:** `get_country_for_appellation()`
- **Appellation → region + sub_region:** `get_region_for_appellation()` — D-08 locked
- **Grape → color:** `normalize_grape_name()` + `get_grape_color()`
- **Vintage plausibility:** 4-digit year between 1800 and `now+1`; checks `appellation_rules.first_vintage` when available
- Tier 3 ontology cache: checks `_memory_cache[_cache_key_region(appellation)]` before any DB call
- All ontology imports and calls inside `try/except` — returns `{}` on any DB error (T-12.1-01)
- `_should_infer(fc, field_name)` helper: only fills if field absent or confidence < 0.8

**Section 2 — `select_model()` + field sets (D-02)**
- `HAIKU_FIELDS = frozenset({"color", "primary_type", "sweetness_level", "is_blend"})`
- `SONNET_ESCALATION_FIELDS = frozenset({"tasting_notes", "description", "food_pairing", "producer_bio"})`
- `select_model(field_name, ontology_hint_conf, attempt)` → `"haiku"` | `"flash"` | `"sonnet"`
  - Haiku: field in `HAIKU_FIELDS` or `ontology_hint_conf > 0.7`
  - Sonnet: `attempt >= 2` (any field escalated after Flash failure)
  - Flash: default for attempt 1

**Section 4 — `resolve_conflict()` (D-05)**
- Returns `(resolution: "auto"|"human", reason: str, winner: dict|None)`
- Auto-resolve: Tier-A vs Tier-C, Tier-A vs Tier-B (both require `fetch_verified=True`)
- Auto-resolve: 2+ Tier-B candidates agree on same normalized value
- Escalate: Tier-A vs Tier-A, Tier-B vs Tier-B disagreement, no clear winner

**Section 5 — `merge_conflict_candidates()` (Bug #3 fix)**
- Deep-merges `{field: [candidates]}` dicts instead of replacing
- Deduplicates by `source_url` to avoid double-counting same citation

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical functionality] Ontology imports deferred to function body**
- **Found during:** Task 2 implementation
- **Issue:** Plan said `from services.ontology_normalization import ...` at module top, but `ontology_normalization` itself does `create_client(supabase_url, supabase_key)` at import time — would crash in test environments without Supabase configured
- **Fix:** Moved ontology imports inside `run_layer1_inference()` body, inside `try/except` blocks. This preserves the zero-crash guarantee (T-12.1-01) and keeps all 24 existing tests green without any mocking.
- **Files modified:** `services/research_agent_helpers.py`
- **Commit:** c62fca6

**2. [Rule 1 - Bug] Tier 3 cache uses _memory_cache directly (not get_entity_cache)**
- **Found during:** Task 2 implementation
- **Issue:** `get_entity_cache` applies a TTL check against `ttl_days` parameter but `run_layer1_inference` needs instant in-memory lookup (no TTL filtering at read time for appellation rules). Using `_memory_cache` dict directly is correct for Tier 3 ontology entries.
- **Fix:** `run_layer1_inference` reads/writes `_memory_cache` directly (the same shared OrderedDict), consistent with the D-04 Tier 3 spec ("In-memory LRU, populated by Layer 1 deterministic inference"). `get_entity_cache` continues to be the general-purpose helper for Tier 1/2 keys.
- **Commit:** c62fca6
