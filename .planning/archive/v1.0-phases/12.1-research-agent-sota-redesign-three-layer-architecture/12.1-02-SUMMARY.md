## What Was Built

### Task 1 — research_routes.py (5 changes)

**Change 1: Auth on POST /trigger (D-06 Bug #7)**
- Added `verify_admin_token()` FastAPI dependency: reads `X-Admin-Key` header, compares to `ADMIN_API_KEY` env var, raises 401 on mismatch or empty env var
- Applied as `Depends(verify_admin_token)` on `trigger_research()` function signature

**Change 2: Scale-safe metrics queries (D-06 Bug #9)**
- `research_run_stats`: added `.order("created_at", desc=True).limit(10000)` + `regression_blocked_count` column
- `evidence_citations`: narrowed from 6 columns to 3 (`source_tier, fetch_verified, corroboration_count`) + `.limit(10000)`
- `research_runs`: added `.limit(10000)`
- `field_corrections`: added `.limit(10000)`

**Change 3: Per-tier fetch_verify_pass_rate (D-07)**
- Added `tier_verified` / `tier_total` dicts computed in a single pass over `cit_rows`
- `fetch_verify_pass_rate_by_tier: {"A": float, "B": float, "C": float}` included in `evidence_hygiene` response

**Change 4: Computed regression_rate (D-06 Bug #6 — metrics side)**
- Replaced hardcoded `0.0` with `sum(regression_blocked_count) / sum(fields_targeted)`
- Falls back to 0.0 via `_safe_div` when no stats rows exist

**Change 5: GET /challenges endpoint (D-07)**
- New endpoint `GET /api/v1/research/challenges` with `status`, `limit`, `offset` query params
- Queries `resolution_challenges` table with `count="exact"` for total and paginated rows
- Returns `{"challenges": [...], "total": int}`

## Deviations from Plan

### Auto-adjusted: citation_completeness proxy (Rule 2 — correctness)

**Found during:** Task 1, Change 2
**Issue:** The plan narrowed `evidence_citations` select to 3 columns, dropping `source_url`, `snippet`, and `retrieved_at`. The original `citation_completeness` computation checked all three dropped columns. Using them after the select change would return empty/None for every row → completeness always 0.0.
**Fix:** Changed `citation_completeness` proxy to `corroboration_count >= 1` (a citation with ≥1 corroboration is "complete" in the sense that it has been cross-referenced). This is semantically reasonable and uses only the columns present in the narrowed select.
**Files modified:** `services/agent-orchestrator/api/research_routes.py`
