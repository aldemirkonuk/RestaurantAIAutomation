Create `tests/e2e/__init__.py` (empty marker).

Create `tests/e2e/conftest_e2e.py` with:

1. **`mock_supabase_tables` fixture** — a factory function that accepts a dict of `{table_name: MagicMock}` and returns a MagicMock Supabase client whose `.table(name)` dispatches to the right mock. Pattern from test_studio_e2e.py `_table_side_effect`. This replaces having to build per-test Supabase mocks from scratch.

2. **`jwt_factory` fixture** — function `make_jwt(payload: dict, secret: str = "e2e-secret") -> str` using PyJWT. Includes pre-built payloads: `DEVELOPER_JWT`, `ADMIN_JWT`, `CONTRIBUTOR_JWT` as module-level constants.

3. **`e2e_settings` fixture** — returns mock settings object with `supabase_jwt_secret`, `supabase_url`, `supabase_key`, `trust_level_threshold`, `manager_email`, `gmail_user`, `gmail_password` all set to test values.

4. **`e2e_report` fixture (session-scoped)** — collects test results (name, status, duration, steps, error details) into a list, writes to `test-results/e2e-report.json` at session teardown.

5. **`mock_extraction_result` fixture** — returns a mock `ClaudeExtractionResult` with 3 wines, each having `field_confidence` JSONB with wine_name (0.95), vintage (0.88), region (0.65), country (0.45). Mimics real extraction output.

6. Import `test_client` from parent conftest.py (pytest discovers it automatically via conftest.py in parent dir — no explicit import needed).

Create `tests/e2e/report_generator.py`:
- A pytest plugin class `E2EReportGenerator` implementing `pytest_runtest_makereport` and `pytest_sessionfinish` hooks.
- Collects: test nodeid, outcome (passed/failed/skipped), duration, longrepr (error details).
- At session finish: writes `test-results/e2e-report.json` with schema:
  ```json
  {
    "generated_at": "ISO timestamp",
    "total": N, "passed": N, "failed": N, "skipped": N,
    "tests": [
      {
        "name": "test_nodeid",
        "outcome": "passed|failed|skipped",
        "duration_s": float,
        "error": null | {"message": str, "traceback": str},
        "timestamp": "ISO timestamp"
      }
    ]
  }
  ```
- Register as a conftest plugin: add `pytest_plugins = ["tests.e2e.report_generator"]` line in conftest_e2e.py, or register via conftest `pytest_configure` hook.

Per D-02: all mocks, no live DB dependency.
Per D-04: JSON error reporting with step/error/stack trace.
