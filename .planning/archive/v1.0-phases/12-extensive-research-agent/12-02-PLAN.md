**Step B — Create services/agent-orchestrator/jobs/research_tasks.py:**

Structure:
1. Celery task entry point `research_agent_task(submission_id, dry_run=False)`
2. Async coroutine `_research_async(submission_id, dry_run)` with:
   a. Load submission from Supabase
   b. Eligibility check (is_eligible_for_research)
   c. Create/load research_run row
   d. Call `_process_record(submission, run_id, settings, dry_run)` — returns stats dict
   e. Write research_run_stats row
   f. Update last_research_run_at on submission
   g. Update research_run row (completed_at, status, fields_filled, cost_usd)

3. `_process_record(submission, run_id, settings, dry_run)` — the evidence loop:
   a. Get target_fields from get_target_fields(fc, RESEARCH_PRIORITY_FIELDS)
   b. call_counter = 0, record_cost = 0.0
   c. For each target_field:
      - If call_counter >= settings.research_max_calls_per_record: break (stop rule)
      - If record_cost >= settings.research_max_cost_per_record_usd: break (budget ceiling)
      - Build query: build_serper_query(field_name, wine_name, producer, vintage)
      - Execute Serper search → list of {url, title, snippet} (increment call_counter by 1)
      - Log cost to api_spend via SpendLogger (provider="serper", model="search", cost_usd≈0.005)
      - Extract candidates from snippets via Gemini Flash (increment call_counter by 1)
        - Send snippets to Gemini Flash with prompt: "Extract value for {field_name} from these
          search results for wine '{wine_name} {vintage}'. Return JSON:
          [{value, source_url, snippet_used, confidence}]. If not found, return []."
        - Classify each candidate's source_url tier via classify_source_tier()
      - Detect conflict: if detect_conflict(candidates) → write to conflict_candidates JSONB, skip
      - Fetch-verify top candidate (if research_fetch_verify_enabled AND call_counter < max - 1):
        # Three-tier verification pipeline (locked in 12-CONTEXT.md Decision 5):
        # 1. httpx async GET (fast path, ~0.3–0.8s)
        # 2. Playwright full render if: response < 2KB, no wine keywords, OR source_tier == "A"
        # 3. Semantic match: normalize both (lowercase + diacritics stripped via unicodedata),
        #    word-boundary regex; if fails, Levenshtein distance ≤ floor(len(value) × 0.15)
        #    Numeric fields (alcohol_pct, vintage, price): exact numeric match after stripping
        # URL cache: check evidence_url_cache table before fetching; cache hit = skip HTTP
        - Tier-1: httpx GET source_url with User-Agent header
        - If response < 2KB OR no wine keywords OR source_tier == "A": Playwright render
        - Normalize + semantic match proposed_value against page text
        - Set fetch_verified = True/False (increment call_counter by 1)
        - Store page_text in evidence_url_cache for 7 days (prevent redundant re-fetches)
      - Corroboration check: should_auto_promote(candidates_with_tier) → (can_promote, conf_key)
      - If not can_promote and no evidence: skip field
      - Regression guard: check_regression_guard(field_name, confidence, existing_fc) → bool
      - Build citation record: build_citation_record(...)
      - Accumulate: new_fc_entries[field_name] = {value, confidence, source: "research_agent"}
      - Accumulate: citation_records.append(citation_record)
      - record_cost += serper_cost + gemini_cost

4. `_write_results(submission_id, new_fc_entries, citation_records, conflict_updates,
                   run_id, existing_fc, null_rate_before, call_counter, record_cost, dry_run)`:
   a. Merge: updated_fc = merge_field_confidence(existing_fc, new_fc_entries)
   b. Route: accepted, review_fields, rejected = route_fields_by_threshold(updated_fc)
   c. Write field_review_queue rows for review_fields (status="pending")
   d. Write evidence_citations rows (batch insert)
   e. Update master_wine_library_submissions:
      - field_confidence = updated_fc
      - conflict_candidates = {existing} merged with conflict_updates (per-field JSONB merge)
      - last_research_run_at = NOW()
   f. Return stats: {fields_filled, fields_conflicted, fields_unchanged, cost_usd, attempts, null_rate_after}

Key invariants to enforce:
- SpendLogger.log() call wrapped in try/except — spend logging NEVER interrupts task (same contract as haiku_tasks.py)
- All Supabase writes wrapped in try/except with meaningful error logging
- If dry_run=True: all computation runs but NO Supabase writes occur (useful for testing)
- `field_review_queue` insert uses same pattern as onboarding_routes.py Phase 7

```python
@celery_app.task(name="research.daily_budget_check")
def research_daily_budget_check_task():
    """
    Checks today's research API spend against the daily cap.
    Writes result to a simple module-level flag that research_agent_task reads.
    This is an advisory check — the authoritative check is inside research_agent_task itself.
    """
    asyncio.run(_check_daily_budget())

async def _check_daily_budget() -> bool:
    """Returns True if budget remaining. Also callable from research_agent_task pre-flight."""
    from config.settings import get_settings
    from services.supabase_client import get_supabase_client

    settings = get_settings()
    supabase = get_supabase_client()
    today = datetime.now(timezone.utc).date().isoformat()

    try:
        result = supabase.table("api_spend").select("cost_usd").eq("provider", "serper").gte(
            "timestamp", today
        ).execute()
        total_today = sum(r.get("cost_usd", 0) for r in (result.data or []))
        return total_today < settings.research_daily_budget_usd
    except Exception as e:
        import logging
        logging.getLogger(__name__).warning("Budget check failed (fail-open): %s", e)
        return True  # Fail open — infra failure should not block research
```

|----------|-------------|
| Serper API → task | Search results (URLs, snippets) are untrusted external text |
| fetch-verify HTTP → task | Response body from arbitrary URLs is untrusted content |
| task → field_confidence | Agent writes to canonical field data — must not regress |
| task → api_spend | Cost tracking — must not interrupt task if logging fails |
