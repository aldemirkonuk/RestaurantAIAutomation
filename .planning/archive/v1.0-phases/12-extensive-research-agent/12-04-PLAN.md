1. **Setup**: Insert a test submission into master_wine_library_submissions via Supabase test client
   with field_confidence = {} (all NULL). Use a known wine: "Brunello di Montalcino 2018".
   Record the submission_id.

2. **Mock Serper**: Patch the Serper HTTP call (whatever function/method Plan 02 uses) to return
   MOCK_SERPER_RESPONSE for any query.

3. **Mock Gemini candidate extraction**: Patch the Gemini Flash call to return structured candidates:
   ```json
   [
     {"value": "Sangiovese", "source_url": "https://www.consorziobrunellomontalcino.it/en/the-brunello/",
      "snippet_used": "produced exclusively from Sangiovese Grosso", "confidence": 0.90},
     {"value": "Tuscany", "source_url": "https://www.wine-searcher.com/find/biondi+santi",
      "snippet_used": "estate located in Montalcino, Tuscany, Italy", "confidence": 0.85}
   ]
   ```
   Return appropriate values for each field_name in the lambda/side_effect.

4. **Run agent**: Call `research_agent_task(submission_id, dry_run=False)` directly (not via Celery).

5. **Assert fills**: Query evidence_citations WHERE wine_id = submission_id.

   - Assert all rows have source_url != ''
   - Assert all rows have snippet != ''
   - Assert all rows have retrieved_at IS NOT NULL

   - Count fields with confidence > 0.5 (previously all were 0.0/null)
   - Assert at least 3 fields now have confidence > 0.5

7. **Assert null_rate improved**: Query research_run_stats WHERE wine_id = submission_id.
   - Assert null_rate_after < null_rate_before

8. **Assert metrics endpoint**: Use FastAPI TestClient on the app.
   ```python
   from fastapi.testclient import TestClient
   from main import app
   client = TestClient(app)
   response = client.get("/api/v1/research/metrics")
   assert response.status_code == 200
   body = response.json()
   assert "gap_closure" in body
   assert "quality" in body
   assert "evidence_hygiene" in body
   assert "throughput_cost" in body
   assert "safety" in body
   assert body["evidence_hygiene"]["citation_completeness"] > 0
   ```

9. **Teardown**: Delete test submission and related rows (evidence_citations, research_run_stats,
   research_runs WHERE id = run_id) to keep test DB clean.
