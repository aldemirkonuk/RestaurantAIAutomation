from pathlib import Path
import json, random, shutil

PROJECT_ROOT       = Path(__file__).resolve().parent.parent.parent
ANNOTATION_IMAGES  = PROJECT_ROOT / "datasets" / "annotation_images"
OUTPUT_BASE        = PROJECT_ROOT / "datasets" / "wine_menus"
SCREENSHOTS_JSON   = PROJECT_ROOT / "datasets" / "annotation_tasks" / "screenshots.json"

**2. ls_to_yolo function (exact formula — do not alter):**
```python
def ls_to_yolo(x_pct, y_pct, w_pct, h_pct):
    """Convert Label Studio percentage coords to YOLO normalized xywh."""
    x_center = (x_pct + w_pct / 2) / 100.0
    y_center = (y_pct + h_pct / 2) / 100.0
    width    = w_pct / 100.0
    height   = h_pct / 100.0
    return x_center, y_center, width, height
```

**3. parse_task function:**
- Extract filename: `task["data"]["image"].split("d=datasets/annotation_images/")[-1]`
- Loop: `for pred in task.get("predictions", [])` → `for r in pred.get("result", [])`
- Filter: `if r.get("type") != "rectanglelabels": continue`
- Filter: `if label not in LABEL_TO_CLASS_ID: continue`
- Return: `(filename, list_of_(class_id, x_c, y_c, w, h)_tuples)`

**4. stratified_split function (seed=42, splits: 70/20/10):**
- Accepts screenshot_tasks and pdf_tasks as separate lists
- Applies split independently to each group using `random.seed(42)` set once before any shuffle
- Returns `(train_files, val_files, test_files)` — lists of image filenames (strings)
- Use `int(n * 0.70)` for train cutoff, `int(n * 0.20)` for val cutoff; test = remainder

**5. main() function:**
- Load both JSON files
- Separate tasks by `task["data"]["source_type"]` ("screenshot" vs "pdf")
- Build label_map: `{filename: [(class_id, x_c, y_c, w, h), ...]}`
- Call stratified_split
- For each split (train/val/test):
  - Create `OUTPUT_BASE/images/{split}/` and `OUTPUT_BASE/labels/{split}/` via `.mkdir(parents=True, exist_ok=True)`
  - `shutil.copy(ANNOTATION_IMAGES / fname, img_dir / fname)` for each file
  - Write label file: `lbl_dir / Path(fname).stem + ".txt"` — write one line per box: `f"{cid} {x:.6f} {y:.6f} {w:.6f} {h:.6f}\n"` — write empty file if no boxes
- Print summary: total images per split, total boxes per split

**Anti-patterns to avoid (from research):**
- DO NOT filter by label string without also checking type == "rectanglelabels" — textarea and choices entries share the same id and have the same coordinates; processing them would triple-count boxes
- DO NOT use original_width/original_height in the coordinate formula — percentage coords are already dimension-independent
- DO NOT skip creating the label .txt file for images with zero valid boxes — write an empty file
