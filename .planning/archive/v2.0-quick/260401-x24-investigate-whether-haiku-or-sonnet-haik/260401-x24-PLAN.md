<objective>
Benchmark claude-haiku-4-5-20251001 against claude-sonnet-4-6 on the same Phase 1 menu images to determine whether field completeness >= 0.95 can be maintained at lower cost using Haiku or a hybrid routing strategy.

Purpose: Phase 1 currently commits to Sonnet at $3/$15 per million tokens. Haiku costs roughly 10x less. If Haiku matches quality at <= 200ms/page the pipeline cost drops significantly — critical for the < $0.50/restaurant target.
Output: Benchmark script, raw JSON results, REPORT.md with recommendation.
</objective>

  <action>
Create `scripts/benchmark_haiku_vs_sonnet.py` as a self-contained async Python script. It must:

1. Import `EXTRACTION_PROMPT` and `COMPLETENESS_FIELDS` from
   `services/agent-orchestrator/services/claude_vision_extractor.py` so the prompt is
   identical to the production extractor. If import fails due to path, inline the same values.

2. Define model configs at the top:
   ```python
   MODELS = [
       {
           "id": "claude-sonnet-4-20250514",
           "label": "sonnet",
           "price_input_per_m": 3.0,
           "price_output_per_m": 15.0,
       },
       {
           "id": "claude-haiku-4-5-20251001",
           "label": "haiku",
           "price_input_per_m": 0.80,
           "price_output_per_m": 4.00,
       },
   ]
   ```

3. Image selection: glob `datasets/annotation_images/*.png`, sort, take first 10 images.
   This caps benchmark cost to roughly $0.10–$0.30 total.

4. For each model x each image (asyncio with Semaphore(3) to respect rate limits):
   - base64-encode the image
   - call `anthropic.AsyncAnthropic().messages.create(...)` with `max_tokens=4096`
   - record: `latency_ms` (time.monotonic around the API call), `input_tokens`,
     `output_tokens`, `cost_usd` (computed from token counts + pricing)
   - parse JSON response, compute `field_completeness` = fraction of
     `["wine_name","vintage","price_bottle","region","country","section_name"]`
     that are non-null, non-empty across all wines on the page (average per wine)
   - on parse error: record `parse_error: true`, `field_completeness: 0.0`

5. Aggregate per model: `avg_field_completeness`, `p50_latency_ms`, `p95_latency_ms`,
   `total_cost_usd`, `parse_error_count`, `avg_wines_extracted`.

6. Write raw results to `scripts/benchmark_results/haiku_vs_sonnet_results.json`:
   ```json
   {
     "run_at": "<ISO timestamp>",
     "images_tested": 10,
     "models": {
       "sonnet": { "per_image": [...], "aggregate": {...} },
       "haiku":  { "per_image": [...], "aggregate": {...} }
     }
   }
   ```

7. Print a summary table to stdout:
   ```
   Model    | Avg Completeness | p50 Latency | p95 Latency | Total Cost
   sonnet   |     0.94         |   2340ms    |   3800ms    |  $0.18
   haiku    |     0.88         |    950ms    |   1500ms    |  $0.03
   ```

Create `scripts/benchmark_results/` directory if it does not exist. Use `ANTHROPIC_API_KEY`
from environment (script fails fast with a clear message if key is missing).
