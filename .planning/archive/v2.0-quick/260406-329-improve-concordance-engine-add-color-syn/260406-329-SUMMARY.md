# Quick Task 260406-329: Improve Concordance Engine — Add Color Synonyms & Grape Variety Substring Matching

**One-liner:** Reduce false contradictions by adding COLOR_SYNONYMS dict (26 color variants) and grape variety substring matching for blend breakdowns.

## Context

The smoke test (260406-2hy) revealed false contradictions where web data is more descriptive (e.g., "deep garnet" vs "red", "87% Cabernet Sauvignon..." vs "Cabernet Sauvignon") but semantically concordant. These false contradictions trigger unnecessary human review and reduce automation efficiency.

## What Was Built

### Task 1: Add COLOR_SYNONYMS dict and grape variety substring matching to check_concordance()

**Commit:** 1b608cd

**Changes:**
1. Added COLOR_SYNONYMS dict after REGION_ALIASES (line 69) with 26 color variant mappings:
   - Red variants: red, ruby, garnet, deep garnet, crimson, burgundy, cherry, brick red
   - White variants: white, pale yellow, golden, straw, lemon, greenish
   - Rosé variants: rosé, rose, pink, salmon
   - Amber/Orange: amber, orange

2. Updated `_normalize_for_compare()` to apply COLOR_SYNONYMS for color field (line 257)

3. Added grape_variety substring matching logic to `check_concordance()` (line 302):
   - If existing value is substring of web value → return "web_data_more_complete"
   - If web value is substring of existing value → return "concordance" (less specific, not contradictory)
   - Otherwise → normal string comparison

4. Updated `check_concordance()` docstring to document new return value "web_data_more_complete"

5. Updated `apply_concordance_result()` to handle "web_data_more_complete" case (line 365):
   - Replace existing value with more complete web value
   - Boost confidence to max(0.90, web_confidence)
   - Set verification_status="web_enriched" to distinguish from exact concordance
