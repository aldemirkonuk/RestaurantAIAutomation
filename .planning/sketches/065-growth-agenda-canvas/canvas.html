The one thing that changed today — OD-53, settled by fetch

(a) Perplexity search-history endpoint NO

The complete published endpoint index — Router, Agent, Search, Embeddings, Sonar, Auth, Analytics — contains no endpoint returning a user's own searches, threads, or Library. The one list endpoint returns async API requests, not web-app searches. The API is zero-retention by policy, so there is no store a history endpoint could read. A staff reply dated 2025-06-08 promised it "by end of August 2025"; twelve months on it is absent.

(b) AnswerThePublic API EXISTS · ALPHA

Enabled per workspace at Account → API Access; personal access tokens; 60 req/min per token; keyword research only (create searches, retrieve reports, request AI answers). Paid plans only — not on free. Searches spend plan credits; same keyword/language/region inside 24h reuses rather than re-spends. Starter $20/mo · Growth $99/mo · Business $199/mo.

The three seams — a seam with two owners has none

The 404

G4 decides→G5 objects

G4 owns the status code, and it lives at the host — a rewrite cannot produce a 404. G5 owns what the page says and where its CTA goes. Neither ships it alone, which is exactly why it has not shipped. GRO-14 forces the naming.

The FAQ link graph

G2 decides→G4 objects

G2 authors the pages and the back-links; G4 objects on thin-content and duplicate-intent grounds before publication, never after. Ten near-identical answers are the doorway-page shape, and distinctness is decided before drafting.

Funnel instrumentation

G5 decides→Compliance objects

G5 states what must be measured; Compliance holds the pen on every word of the notice. Growth never drafts privacy copy. GRO-13 turns the coupling from a convention into a blocking check.

What this agenda will not do

Locks, honoured — not worked around

  • Pricing is deferred. No tier, no number, no page designed "for later". GRO-3 proposes a spend brief about someone else's product, never a price for ours.
  • Brand and landing visuals are held. GRO-15 produces a sentence and a slot's logic; this canvas is an agenda one-pager, not a landing page.
  • No target list. Sales owns it, founder-deferred.
  • No agent publishes. Drafts propose; a human publishes. mutate_stock_money_outbound: confirm is a constant on the department card.
  • The register is not ours to edit. Growth supplies OD-53's dated lines; the Decision Office writes the row.

The three zeros — any non-zero is a department escalation

  • gate_bypass_count = 0 One bypass invalidates the pipeline, not one article. Read weekly, because a bypass is discovered, not reported.
  • fabricated_social_proof_count = 0 Absolute; unrecoverable if breached. The soft version arrives first — a case study written from a partner's politeness.
  • over-claims = 0 Dollars recovered means we asked, not we received, until a credit memo lands.

Seeds rejected

  • Brand-voice authoring — a gate enforcing its own opinion is not a gate. Filed as a cross-unit ask.
  • Start the Search Console loop — it has no property; a task that cannot close is the department's first failure mode.
  • A composite growth score — the five numbers are not commensurable; averaging them is a failed run.
