# Sketch 028: Living Cellar

## Design Question
How does the "Living Cellar" vision feel as a primary inventory surface — an isometric spatial twin where bins glow by temperature, velocity, fill %, and dead-stock frost, with lot/vintage-aware placement?

## How to View
```bash
open .planning/sketches/028-living-cellar/index.html
```

## Variants
- **A: Isometric Map** — Full-bleed 2.5D cellar with rack rows, slot heat, and ambient overlays (temp / velocity / dead-stock)
- **B: Map + Detail Split** — Spatial map left, lot-level detail + FEFO pour suggestions right
- **C: Synthesis ★** — Isometric twin + overlay toggles + multi-location lot chips + signature "frost" dead-stock moment

## What to Look For
- Does the cellar feel like a place you want to work in, not a diagram?
- Can you instantly see where problems live (hot rack, dead bin, overfull slot)?
- Does lot/vintage layering make split-stock (cellar + bar) feel natural?
- Is the overlay toggle (temp / velocity / trust) legible at a glance?

## Audit Grounding
Addresses SOTA gaps: one-wine-one-location constraint, flat storage list, no topology, no FIFO/FEFO, no dead-stock visualization.
