# Sketch 029: Cellar Copilot

## Design Question
How should the "Next" and "Bold bet" inventory science layer present itself — ambient forecasting ribbons, ABC-driven count routes, Ghost Inventory trust scores, and a copilot that proposes actions instead of static alerts?

## How to View
```bash
open .planning/sketches/029-cellar-copilot/index.html
```

## Variants
- **A: Forecast Ribbon** — Per-wine days-of-cover sparklines with confidence bands and reorder-by dates above a science-enriched table
- **B: Count Mode** — Agentic cycle-count session: ABC-prioritized walk route, blind count sheet, QR-at-rack flow
- **C: Synthesis ★** — Copilot command bar + forecast ribbon + trust/shrinkage panel + count route preview

## What to Look For
- Does forecasting feel ambient (always visible) without cluttering the table?
- Would a sommelier trust the reorder-by date and confidence band?
- Does Count Mode feel faster than a spreadsheet stocktake?
- Does the copilot propose concrete next actions, not generic AI fluff?

## Audit Grounding
Addresses: static thresholds, no ABC/XYZ, dormant Ghost/Shrinkage agents, no cycle counting, naive 7-day velocity, BTG ml depletion gap.
