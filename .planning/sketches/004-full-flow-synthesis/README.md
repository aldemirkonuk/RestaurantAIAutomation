# Sketch 004: Full Flow Synthesis

## Design Question
Do the three winning variants (001-A/C, 002-C, 003-C) feel cohesive when wired together as a complete user journey?

## How to View
```
open .planning/sketches/004-full-flow-synthesis/index.html
```

## Screens Included
Use the top dev nav to jump to any screen:

### Path A — Join via Invite Code
1. **① Selector** — Desktop: Feature Cards (two equal side-by-side). Mobile: Bold Primary (Create dominant, Join outlined below)
2. **② Code** — Clean monospace input + animated trust card validation
3. **③ Account** — Account form pre-confirmed with the restaurant context banner
4. **④ Welcome** — Dashboard preview showing restaurant stats (immediate value)

### Path B — Create New Restaurant
5. **① Selector** — same as above
6. **⑤ Account** — Step 1: account details
7. **⑥ Restaurant** — Step 2: Left-rail progress (Identity → Location → Contact)
8. **⑦ Verify** — Email verification holding page with step-by-step instructions

## What to Look For
- Does the flow feel like one product or three stitched screens?
- Does the trust card on the code entry screen give enough confidence before the account form?
- Does the left-rail on the restaurant form feel like the right amount of structure?
- Resize to 375px (📱) to see the mobile path selector switch to Bold Primary layout
- Password strength meter on account forms
