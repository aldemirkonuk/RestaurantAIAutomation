Gesture

Skia pour pull-to-refresh

Pull down on the feed and wine pours from the top into a glass indicator. Release past threshold triggers refresh with spring snap-back.

Gesture thresholds

  • 0-40px pull: hint text only
  • 40-120px: pour stream grows, glass fills
  • 120px+: release triggers refresh
  • Refresh: 800ms pour + snap feed, haptic success

Skia implementation

Canvas + Path bezier pour stream tied to pullY shared value. Glass fill = interpolate(pullY, [0,120], [0,1]). Use runOnJS for data fetch on release.
