# Sketch 021: Location Card Design

## Design Question
The card is the core repeating UI unit. Does it whisper (minimal) or speak (data-rich)? Does it feel like a data table or a wine cellar?

## How to View
```
open .planning/sketches/021-location-card-design/index.html
```

## Variants
- **A: Minimal Clean** — Thin top accent bar, large % number, slim fill bar, small metadata row, actions only on hover. Zero noise.
- **B: Data Rich** — Large current bottle count, 3-stat grid (temp/humidity/SKUs), inline top-wines list, always-visible action buttons. No drilling needed.
- **C: Visual / Ambient** — Full-color gradient background per location, giant % as the hero, footer strip for meta. Each card has its own identity.

## What to Look For
- Does A feel sophisticated or too sparse for staff who need detail?
- Does B's mini wine list make the card feel cluttered or useful?
- Does C's color-heavy approach work when you have 8+ locations in a grid?
- Which handles the "Overflow Overcapacity" alert state most effectively?
