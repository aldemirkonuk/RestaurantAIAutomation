# Sketch 005: Branch Selector

## Design Question
Which trigger + dropdown pattern best communicates the active location and chain structure at a glance?

## How to View
open .planning/sketches/005-branch-selector/index.html

## Variants
- **A: Compact pill** — Wine-tinted pill trigger (full-rounded), flat list with uppercase chain labels and dividers
- **B: Rich card ★** — Bordered card trigger showing name + chain/city subtitle, avatar-initial rows with Active badge, "Add location" footer link
- **C: Command-style** — Minimal text trigger, searchable command-palette dropdown with keyboard nav hint

## What to Look For
- Does the trigger alone communicate which location is active + which chain it belongs to?
- Does the chain grouping read clearly without taking up too much vertical space?
- Which "Add location" shortcut placement (B footer vs none) feels natural?
- Does Variant C's search feel useful or over-engineered for 3-10 locations?
