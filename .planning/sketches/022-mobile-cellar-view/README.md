# Sketch 022: Mobile Cellar View

## Design Question
Cellar staff use phones in physical spaces — they need large tap targets, minimal reading, fast actions. Which paradigm fits?

## How to View
```
open .planning/sketches/022-mobile-cellar-view/index.html
```

## Variants
- **A: Quick Scan Hub** — Giant scan button is the hero. Location context chip row. Recent activity feed. One-tap to add a bottle to current location.
- **B: Compact List** — All locations at a glance. Swipe-friendly list items with inline Add + QR actions. Bottom tab bar for navigation.
- **C: Location Focus** — One location at a time with a dark header, circular fill ring, big stats. Swipe dots to navigate between locations. Wine list below.

## What to Look For
- Does A's scan-first approach match how cellar staff actually work (vs. managers who review)?
- Does B feel more like a management tool than a cellar tool?
- Does C's swipe-between-locations paradigm feel intuitive for 4 locations vs. 12+?
- Which handles the "I need to quickly log 20 bottles arriving" workflow best?
