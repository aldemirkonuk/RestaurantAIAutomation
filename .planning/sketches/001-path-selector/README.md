# Sketch 001: Path Selector

## Design Question
How do we make the Join vs. Create choice feel confident and premium — not like a generic auth fork?

## How to View
```
open .planning/sketches/001-path-selector/index.html
```

## Variants
- **A: Bold Primary** — Create = dominant wine-filled card; Join = smaller outlined row below. Clear primary/secondary hierarchy for the target majority (new owners).
- **B: Split Canvas** — Full-screen left/right split. Dark wine panel = Create, light panel = Join. Premium SaaS feel, dramatic visual differentiation.
- **C: Feature Cards** — Two equal-weight cards side by side with benefit bullets. No hierarchy, but benefit copy does the persuasion work.

## What to Look For
- Which variant makes it instantly obvious what to do without reading?
- Does the primary action (Create) feel trustworthy and premium?
- Does the secondary action (Join) feel equally discoverable without competing?
- Which feels most like a premium B2B SaaS and least like a generic signup?
