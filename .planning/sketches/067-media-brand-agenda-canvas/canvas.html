Found on 2026-08-28 by re-measuring instead of carrying forward

The burn-down is running backwards
Name 351 → 360 lines, domain 33 → 39, in four days, with nobody editing brand strings on purpose. A surface with no ratchet does not hold still; it accretes. This single fact reorders the agenda — MB-4 before MB-7.
The tier model has three tiers; the surface has five classes
Class 4 — externally-held account identity: gmail-push@wineops.iam.gserviceaccount.com and wineops.ai@gmail.com name a Google Cloud project and a Gmail account. Migrating them happens at Google, not here, and invalidates every credential minted against them.

Class 5 — third-party observability identity: service_name="wineops-agent-orchestrator" is the name this company appears under in a monitoring vendor's dashboard. Renaming it forks the time series; the history does not follow the name.

Neither is a display string, and neither is a workspace scope. The quarterly inventory loop exists because "each scan searched for what it already knew about" — on day one, it did that again, and this is the correction.
The consent record is enforced by nothing
consent_purpose, consent_captured_via and consent_withdrawn_at appear in exactly one file in the repository — the migration that creates them. No code under apps/ or services/ reads any of the three. The M4 card consumes "the consent gate owned by privacy-engineering — called, never reimplemented": it names a callee that does not exist. The premortem assumed the missing thing was the register. It is one layer lower than that.
Citations rot in days, and one of them inverted
Three of eleven tier-1 rows no longer resolve — gmail.service.ts:78→79, vendor-page-extractor:17→26, push.ts:32→33. Worse: a card cites "PROJECT.md:101 — DEP-06, still unchecked". PROJECT.md holds no DEP-0 string at all; DEP-06 lives at 07-reference/REQUIREMENTS.md:333 and is recorded checked. The card names a blocker its own source says is cleared.
Throwaway-grade. A thinking surface for one agenda, not a product and not a template. Source of truth is media-brand-agenda-full.md; if this canvas disagrees with it, the canvas is stale.
