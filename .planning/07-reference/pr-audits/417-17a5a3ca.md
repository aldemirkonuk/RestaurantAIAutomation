## Why it blocked

Both reviewers, independently and by their own mutations, showed that this sentence, written by this PR into ADR 0158's
cutover item 6 and into the `resolved` CLAIMS row `ADR-0158-TOKEN-ROUTES-ARE-CHECKED-LIVE`, is not true as written:

> `crawl-surface.test.ts` fails on any rule that matches a token route and disagrees, wherever it sits

- A rule gated on a host outside the three hardcoded strings (`crawl-surface.test.ts:69`) is skipped, not flagged
  (`conditionHolds` returns false).
- A rule whose source is the trailing-slash form (`/verify-email/`) is never matched, because the guard probes only
  slashless samples.
- Rule sources are evaluated as JavaScript regular expressions, not Vercel's path-to-regexp; only a `:name`
  parameter and a cookie / query / regex / string-host condition throw.

CLAUDE.md §5b: a `resolved` claim must hold. Item 6 is also a cutover instruction addressed to the next session, whose
own PR (#418) is waiting on this one. The code is sound; the register entry and the ADR instruction were not yet true.

## A live finding both reviewers reproduced, and the author reproduced a third time

On production (`mudavym.com`, main at `0c1422c8d`, measured 2026-09-21): `/reset-password/`, `/reset-password/?token=x`
and `/verify-email/` answer 200 with **no** `Referrer-Policy` and **no** `X-Robots-Tag` header. The HTML
`<meta name="robots" content="noindex, nofollow">` is present, and the emails link the slashless form
(`auth.service.ts:980`, `:2145`), so practical exposure is small. The token rule's source has no optional trailing slash
(`apps/web/vercel.json`, from PR #385), so this predates #417; neither the guard nor the census probes that form.

## What held

The guard catches a site-wide `Referrer-Policy` appended after the token rule, a site-wide `X-Robots-Tag: all`, a
deleted token rule, a lower-cased key, a query / string-host / regex-host condition, `:x?`, `(?<t>...)` and `/verify-.*`
sources (the auditor's own 22 mutations); it correctly passes an unrelated header, a duplicate `no-referrer`, and a
lookahead source that leaves the token routes out. The census reads split and duplicated fields correctly. The gate's
marker in the tag-along file cannot satisfy any merge gate.
