## Found, not fixed (and why)

- **Turns and DIO use unlike bases.** Whole-cellar value is set against the cost of goods of till-mapped items only, so unmapped wine lines inflate DIO. This is an interpretation fork; it needs a decision.
- **Stale stored value for owners and managers.** Under a live refusal, they still see the stored `current_value`.
- **Insight feed says "0% of the way" for every goal.** #722's producer lane.
- **Staff still see `wine_revenue` / `avg_check` goals.** ADR 0298 d9 scope.
- **"cost cost"** in #1036's costed-items note.
- **No production backfill** of draws the old `revalue_lot` left unsettled. The count query is in the #1087 body.
- **Claims check: 1 STALE row** (`ADR-0298-GATEWAY-READS-THE-TILL`). It is already stale on the #1036 base, not caused here.
- **Horizontal overflow at 1440 emulation.** /reports scrollWidth was 1528.
  - The grid items are laid out at 1280 while the `.react-grid-layout` container is 1124.
  - The grid is `WidthProvider(Responsive)` in `Sheet.tsx` (react-grid-layout 2.2.2), and a window resize event did not correct it.
  - At "mobile" emulation the pane still reported innerWidth 1296, so the emulation itself is suspect. It is unconfirmed whether this is real or an emulation artifact, and it is not the cost-math lane.
- **Seed artifact.** `stock_live` had been seeded without lots, so the cellar value changed when lots arrived.
