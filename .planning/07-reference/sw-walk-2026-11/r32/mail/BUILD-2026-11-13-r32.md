Rejected: `unaccent` (not in corpus); a folded generated column + trigram index (schema change for a 50-row page); folding only the first N chars of a letter (misses late words).
6. **Files open through a 5-minute signed link fetched on click**, tab opened synchronously first so pop-up blockers allow it, `opener` cut. Rejected: signed URLs in the thread payload (expire while the page is open; leak in logs); a gateway byte proxy (bigger surface, no gain).

8. **A failed files read does not fail the thread**: `attachmentsRead:false` and one line saying it does not mean there are none. Rejected: 503 for the thread (one table outage hides all mail).

## Browser checks (local stack only, after the stack is merged into a local build)

Route for all: `/communications?tab=mail`.

1. **Letter count.** Owner. Open a vendor whose thread holds one received letter and one house letter still queued (or a draft). The thread row reads "1 letter", not "2 letters". A thread holding only a draft shows no count.
2. **Search by name.** Owner. Type `sut` in the box labelled "Search mail" (placeholder "Find a vendor, subject, order number or word"). After about a third of a second only the vendor named "Süt …" is listed. `SUT` and `süt` give the same list.
3. **Search by subject / order number / letter words.** Type part of a thread subject in another case (e.g. `spring prices`), then an order number (e.g. `po-777`), then a word that only appears inside one letter. Each time the matching vendor is listed.
4. **Plain text.** Type `fish.co` (vendor "Fish Co" exists): no one. Type `bread (50`: no error; the list says "No one in this house's mail matches “bread (50”. The search reads names, subjects, order numbers and the words of each letter."
5. **Clear.** Press Escape in the box: the full list returns. Type again and click "Clear": same. From the empty message click "Clear the search": same.
6. **With Waiting on you.** Turn the "Waiting on you" chip on and search a vendor who is not waiting: "No one waiting on you matches “…”. The search reads names, subjects, order numbers and the words of each letter."
7. **Staff and withheld drafts.** Staff. Search a word that appears only in a house draft (HOUSE_DRAFT): no one. Owner, same word: the vendor is listed.
8. **Length.** Paste 150 characters: the box stops at 100.
9. **Files.** Owner. Open a thread whose vendor letter came with a PDF (local seed: a `conversation_attachments` row + an object in bucket `vendor-attachments`). Under the letter: paperclip, file name, "PDF, <size>", and "Open". Click Open: a new tab opens the file; the Mail tab stays.
10. **Removed file.** Set that row's `bytes_deleted_at`. Reload: the line reads "The file was removed under the retention rule, <when>; its name is kept." with no Open.
11. **Pop-up blocked.** Block pop-ups for the local origin and click Open: "The browser did not open a new tab. Open <name> (this link works for five minutes)."
12. **Not this house's file.** As staff of house A, `GET /mail/attachments/<id of a house B file>/link` answers 404 "That file is not in this house's mail."
13. **Files could not be read.** Stop or rename `conversation_attachments` locally and open a thread: letters still show, plus "The files these letters carried could not be read just now. That does not mean there are none."
