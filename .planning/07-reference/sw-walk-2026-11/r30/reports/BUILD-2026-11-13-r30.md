## Decisions (the session's calls, under the 2026-11-07 /goal)

1. **Withhold, not refuse (ADR 0348 decision 3).**
   - A staff caller gets `{withheldForRole: [classes]}`, and the service is never asked.
   - Rejected: a 403. It would turn the routes into errors, and ADR 0348 keeps the routes.
2. **Insights are classified from the catalogue**: `requires`, the measure's unit and the dimension.
   - `checks`→sales, `orders`→suppliers, `inventory`→stock, a currency measure→money, the waiter dimension→people.
   - An unknown key needs the full row: it fails closed for staff and stays open for owners.
   - Rejected: a per-category allowlist. It drifts as the catalogue grows.
3. **Bottle volumes stay open to staff.** ADR 0348 item 3 does not name them, so they wait for a later ruling.
4. **Gap 8 was split.** The gateway half (#1437) sits on #1362's train, which lacks rp-combo. The web half (#1438) sits on #1276's train. The web half offers the combo only when every day carries `checks`.
5. **The till window lives in the URL `?days=`.**
   - Only the offered values 7, 30, 90 and 365 are accepted; anything else reads as 30.
   - Rejected: a preferences write (it races the arranging save on the same sheet) and localStorage (a shared link would not open on the same window).
   - The pick does **not** carry the history state. Carrying it made a full-screen close go back to an entry made before the pick, which reverted the window. My first version had this bug; a test now pins it, and the test fails against the state-carrying version.
6. **Gap 11 (locale) is deferred.** It depends on #1298 and #1319, and en-US strings are pinned in both trains' tests.
