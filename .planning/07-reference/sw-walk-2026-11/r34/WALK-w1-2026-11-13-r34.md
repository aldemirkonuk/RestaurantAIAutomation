## Findings and fix briefs

- **F1. A duplicate custom vendor is accepted (gateway).**
  - `POST /providers` with a custom name that already exists answers 201 and creates a second row, so #1469's 409 sentence is unreachable.
  - Brief:
    - In the providers create path, refuse a case- and space-folded duplicate custom name within the house with 409, carrying the existing id.
    - Add a spec: same name, different case → 409; another house → 201.
- **F2. The plan names no person.**
  - The menu plan says "it was set by hand by no person named on 2026-11-14".
  - Brief: when `set_by` is null, drop the clause ("it was set by hand on …").
- **F3. The read box is stale after Make current.**
  - After Make current, the read box still says "It is not the current menu, and no price has changed." and still offers Make current.
  - Brief: invalidate or refresh the box's menu-status query when make-current succeeds.
