# r22 gateway-message-money: money in gateway emails, notifications, digests and push (2026-11-13)

## The session's calls (full text in each PR body)

1. **A goal is said in the house's currency.** A goal row has no currency, and a goal measures the house's own books.
   - Rejected: a USD default.
   - Rejected: one order's currency.
2. **The places come from ISO 4217 in an explicit table, not from `Intl`.** Measured on Node 22, CLDR gives HUF 0, COP 0, IDR 0 and IQD 0 places. Scaling minor units by those would be 100 times off.
3. **Minor units are not scaled where the provider's convention is not known to match ISO** (ISK, UGX, MGA, IQD, LYD). Those keep the exact minor-unit wording.
4. **All three PRs are stacked on #1193,** which adds `common/money-in.ts`.
   - Rejected: a third byte-identical add of that file.
   - Rejected: adding `currency` to `ScheduledTenant`, which every scheduled job shares.

## Left (not done)

- **Mixed-currency purchase spend (reports lane).** `analytics/goals.service.ts` sums `procurement_orders.total_cost` for purchase_spend with no currency filter. A TRY house with one EUR order gets a mixed sum, and #1279's notice (like /reports) labels it ₺. This code belongs to the reports lane (#1113, #1119, #1132). The fix there is to sum per currency, or to refuse a mixed window.
- **Cosmetic money shapes.** own-wage-notice and credit-letter say "18.50 TRY" and "118.00 EUR". That follows the rule, but the shape differs from the bell's ₺ and has no grouping.
- **A `$` in a server log.** `communications.controller.ts:542` logs `@ $${targetPrice}/bottle`. This is a log line, not a message.
- **Fixed ×100 on provider prices.** `twilio.adapter.ts:261` scales a provider price by a fixed ×100. The result goes to the ledger only, never into message text.
- **Python orchestrator mail** is outside the gateway lane.
- **#1127's own `moneyIn` copy** does not get #1282's places.

## Browser checks needed (local stack only, walk agent)

Use the local stack with #1193, #1279, #1282 and #1288 merged locally, and a TRY house.

1. **Goal notice.**
   - Arm `NOTIFICATION_PRODUCERS`.
   - Seed an active `wine_revenue` goal that `pos_checks` cross.
   - Run the fast sweep, then open /notifications.
   - Expect "Wine revenue stands at ₺… against a target of ₺…", with no `$`.
   - Repeat with `restaurants.currency = NULL`; expect bare figures.
2. **Ceiling notice.**
   - Seed an at_most `purchase_spend` goal whose deadline has passed.
   - Run the daily sweep.
   - Expect "stayed under by ₺…".
3. **Grant notice.**
   - As an owner, issue a vendor-send grant with a limit of 1500.5 TRY under the seal.
   - Open /notifications as a co-owner.
   - Expect "(up to ₺1,500.50, until revoked)".
4. **Credit purchase words.** No web page calls this route.
   - Call `POST /communications/text-credits/purchase` with amountMinor 5000 TRY, against the local gateway in Stripe test mode only.
   - Expect `words` to begin "Charged ₺50.00 to the card on file."
   - Skip this check if no Stripe test key is set locally.
