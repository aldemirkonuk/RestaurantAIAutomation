## Decisions (the session's call under the 2026-11-07 /goal; each is in its PR body)

- **(a) Delete the dead importer, not a lazy boundary.**
  - The only path into the entry was Header → `hooks/queries` barrel → `useSommelierQueries` → `lib/supabase.ts`, whose module-scope `createClient()` defeats tree-shaking.
  - Rejected: `import()` inside the fetchers. That keeps a 170 KB chunk and a browser→Postgres path that ADR 0143 and OD-72 retired, for hooks nobody calls.
  - Rejected: `manualChunks`. It moves the bytes, not the side effect.
  - `lib/supabase.ts` is left in place because #1017 and #1149 edit it.
  - AuthProvider never used Supabase, so it stays the single owner untouched.
- **(b) The context carries a typed wait reason; the words never count down.**
  - The words are an upper bound: "in a few seconds" up to 10 s, else "within a minute". The house loader's rule is that it never counts itself.
  - "Still signed in" only for a known temporary refusal.
  - The slow line comes after 5 s (rejected: 12 s, and showing it at once).
  - Only an offline wait wakes on `online`.
  - Rejected: reusing #1092's SessionWaitScreen. It is the older parallel fix built on main, and it is in the MERGE-ORDER "auth trio" conflict. The words mirror #1092's sentences so the resolver sees one voice.
  - The new test is named `AuthContext.waitReason.test.tsx`, so it does not add/add-collide with #1092's `AuthContext.sessionWait.test.tsx`.
- **Rate limit: KEEP in process memory.**
  - The gateway runs at `replicas: { "us-west2": 1 }` (`.railway/railway.ts:101`).
  - There is no Redis service in the Railway IaC (`railway.ts:150`), `local-stack.sh:191` blanks `REDIS_URL`, and CacheService disables itself without it (`cache.service.ts:28-30`).
  - The open rate-limit PRs #1248, #1168, #1148, #1136, #943 and #906 all keep the Map store.
  - The claim fails the build when replicas go above 1 or the store changes.
  - Not built: there is no shared store in the stack.
