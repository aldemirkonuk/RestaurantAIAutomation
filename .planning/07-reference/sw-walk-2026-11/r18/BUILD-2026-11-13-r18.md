| /inventory | 3,080 / 808 | 2,008 / 535 (41 chunks) |
| /login | 3,080 / 808 | 1,209 / 369 |

The root cause had two halves:
- App.tsx imported InventoryCommandPage, InventoryRoute and Register eagerly.
- `components/ui/index.ts` imported the `@wineops/ui` root. That root re-exports Tremor, which is not side-effect free, so Tremor, Recharts and Headless UI ended up in the entry.

Dropping only the `ui` group grew index to 2.1 MB. It was the barrel fix that shrank it.

Still in the entry:
- framer-motion and motion-dom, about 122 KB;
- the Supabase auth client, about 87 KB;
- Sentry, about 58 KB;
- axios.
