## Calls made (2026-11-07 /goal)

- **Reply-To to the Mudavym address on every house letter whenever one exists.** This is the audit's call, kept after an attempt to break it. Two alternatives were rejected:
  - Setting it only when the sending mailbox is unread is not decidable. `gmail_send` records no address, so nothing proves that the mailbox being read is the one that sent the letter.
  - A plain read that never provisions the address was also rejected. The dispatcher uses `addressFor`, the order path's own call. Sending is an act, so the M-12 read rule does not apply.
- **The composer warns and never blocks, and only on a definite `false`.** An unconfirmed "same mailbox" is `null`, so the composer raises no false alarm.
- **The `where` enum is kept and only the words change.** The web branches on `where`.
- **The reader status speaks for the weakest mailbox.** One status line per mailbox is left for later web work.
- **The day-1 test is "a letter has arrived", not "a mailbox is connected".** Order replies come through the shared mailbox even when the house has connected nothing.
