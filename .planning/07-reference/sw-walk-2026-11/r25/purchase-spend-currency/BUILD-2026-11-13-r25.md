## The session's calls (full text is in each PR body)

1. An order not in house currency withholds the total, like an uncosted order. It is counted and named by code.
   - Rejected: a partial sum with a note. A ceiling goal or a pace would read short.
   - Rejected: converting.
2. An order that names no currency is read as the house's money, because the column has no backfill by design.
   - Rejected: holding it as unstated. That breaks every legacy goal.
3. With an unnamed house currency, any order that names a currency is "not in house currency", and the sentence points to Settings. This matches #933.
4. The house currency is read only when an order names one. A failed read is a 503 refusal, never a 0.
5. Vendor concentration is withheld while other money is present.
   - Rejected: leaving that vendor out, which would understate concentration.
6. The wage notice and credit letter use the bell's `moneyIn` (en-US grouping, a unique narrow sign), not the web house-locale formatter (#1298).
