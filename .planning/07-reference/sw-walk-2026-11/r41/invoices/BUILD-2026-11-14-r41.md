## Decisions (the session's calls, under the 2026-11-07 /goal; full rationale in each PR body)

- P1: share the client read by house (one-line key change, merges clean with the #1077 picker chain) rather than a server names read; the names read is the next slice once the picker reads lazily.
- P2: an opt-in `view=summary` query param rather than changing the default list shape (other callers read `extracted`).
- P5: LATERAL per-row sums rather than an index or a materialized total; `jit = off` on the function because its generic plan's cost guess crossed `jit_above_cost`.
- P6: a grouped view read whole, rather than surfacing `capped` (still hides the oldest), paging all events in the gateway (grows forever), or open-orders-first (bottle-counted orders stay `PARTIALLY_RECEIVED`). One tightening: the order must be the event's own house's.
