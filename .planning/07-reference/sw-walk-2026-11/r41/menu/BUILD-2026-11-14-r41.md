## What each PR does, and the session's call
- **#1665, R1 gateway.** `readTypedLines` reads manual import lines and refuses the whole menu on one bad line, saying "Nothing was kept.". It refuses:
  - a non-list
  - a line with no name
  - a number price that is not finite or is below zero
  - typed text that is not a string

  Typed prices are read by addedPrice/parseMenuPrice, the reader Add and Change price use. With it:
  - "45,50" reads as 45.5.
  - "1.250,00" reads as 1250.
  - "1.250" is refused with both readings.
  - A minus is refused.

  Only known fields are kept, trimmed.
  - Rejected: a web price reader, which would be a third reader (R7).
  - Rejected: dropping the bad line and keeping the rest (a silent loss).
- **#1669, R1 web.** The /menu read box offers "A file" or "Type the menu". The typed form has rows of Name, Section, Glass and Bottle, plus "Another line" and "Leave out".
  - The typed rows are kept through the same box, so they get the same plan and Make it current.
  - An empty row is left out. A row without a name is refused with its line number.
  - Prices are sent as typed.
  - Rejected: Add to menu creating a current menu, because it would skip the plan.
  - Rejected: mounting onboarding's MenuManualEntry (wine-only, "$" columns, parseFloat).
- **#1668, R2.** After Make it current, MenuPlan alone refreshes the menu reads.
  - It refreshes every menu read except its own plan, then the price locks.
  - It calls onDone, then removes its own plan's cached answer.
  - The parents' invalidations are removed.
  - Rejected: excluding every plan, because another open plan would go stale.
  - Rejected: keeping the cached plan.
  - Rejected: refetching and ignoring the answer.
- **#1666, R3.** Independent reads run together:
  - `allInOrder` uses allSettled and says the first failure in the order given, so refusal words and the other-house 404 do not change.
  - `chunksTogether` runs four chunks at a time, the width #1572 chose.

  It applies to computePlan, planFor, makeCurrent, housePricesOf, addToInventory and the carry re-read.
  - Rejected: Promise.all, where the first failure in time would change the words from one call to the next.
  - Rejected: all chunks at once.
- **#1667, R10 + R11.** `useHouseCurrencyRead(house?)` returns `{code, reading}`. useHouseCurrencyCode keeps its signature.
  - MenuNext drops its own money hook. It holds "Reading the menu…" until the money read answers.
  - A failed read does not hold the page.
  - Rejected: printing prices with no money name until the read answers, or with a guessed one.
  - Rejected: keeping two hooks.
