## Findings

2. F2 r43 w5 "375 px /reports page 1296 wide" is NOT a product bug: it appears only while the Browser pane is hidden (requestAnimationFrame and ResizeObserver do not run, so react-grid-layout keeps its 1280 default width and the emulated viewport widens to fit). With the pane shown (show_pane preview) the same build gives innerWidth 375 and 343 px items. Two experiments on Sheet.tsx (measureBeforeMount, overflow-x: clip) were tried while hidden and reverted; nothing to fix. Future walkers: show the preview pane before any layout or width check.
3. Walk method: the privacy and theme dialogs need keyboard Enter twice on the Hold button; the dev bypass is off in a production build, so sessions were set from tok files via localStorage (accessToken, refreshToken, activeRestaurantId).
