## Found, not fixed

- **Letters "Waiting on you · 0" against Mail "4 vendors are waiting on you".** The same words mean different things (drafts and requests against vendors owed a reply). From #587, on `main`.
- **/inventory reads "5 titles, 5,512 bottles"**, counting 5500 g of cheese as bottles. The legacy page shows "5500 / 3 par … btl/day". This is the inventory-units lane (#934, #1022, `fix/inventory-totals-add-up-by-measure`).
- **`landed-cost.ts` `basis` words a weighed line in bottles** ("3000 bottles accepted … 0.45 a bottle"). It is in the verify answer only, and no page renders it.
- **The legacy verify `money()` prints `$` for a TRY invoice**, in the web and the gateway engines.
- **The photo toast here shows "Anthropic API key not configured — set ANTHROPIC_API_KEY".** #1095 (onboarding lane) words this refusal, and this chain lacks #1095.
- **Seed artefacts:** the seed's OOO header used `autoReplied`, and bracket/no-bracket message-ids are not deduplicated by this chain's exact match.
