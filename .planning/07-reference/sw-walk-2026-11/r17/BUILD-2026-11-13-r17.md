## What the flood was (item 1)
The brief's framing was wrong: there is no request loop.
- **Production build** (vite build + preview on 3410, the same VITE_* env), quiet 70-80 s windows:
  - dashboard: 3 GETs (`notifications/unread/count`, `house/day`, `house/counter`, each on a 60 s poll), each preceded by an OPTIONS;
  - /inventory: 3;
  - /reports: 2;
  - /orders: 6-7 (`procurement/conversations/active` polls every 30 s).
- **Vite dev** made the 20.9K. One load of `/` was about 3,555 requests. A module-graph crawl found 3,466 modules, 3,110 of them lucide-react icons, because `optimizeDeps.exclude: ['lucide-react']` dates from the scaffold (6d310068b). A walk's several loads, plus stale 3410 tabs reloading when the stack restarts, add up to r16's count.

Fixes:
- **#1235** drops the exclude, with a guard test.
- **#1236** sets CORS `maxAge` to 600 s. Chrome's default is 5 s, so before it every API read paid a preflight. This one matters in production.
