## The session's calls (delegated under /goal 2026-11-07)

1. **The default window for figures of record.**
   - Call: a request that names no window keeps 365 days, so goals, recommendations and the MCP reader do not change. The /reports page and exports ask for the till window, defaulting to 30.
   - Rejected: changing the default to 30 for every caller. That would silently change the goal and recommendation inputs.
2. **One period control per windowed cutting.**
   - Call: the till and the Figures of record each carry the picker, and both are bound to the same `?days=`.
   - Rejected: a single picker in the till only. The ledger's labels would name a window with no control beside it.
   - Rejected: a picker in the page banner. That redesigns the page beyond this gap.
3. **Calendar on a failed papers read.**
   - Call: every day is withheld, with the reason. Nothing shows which day the unread papers fall on, so showing the orders-only figure would understate spend.
   - Rejected: withholding only the month total. The days would then each read a short sum.
4. **Bottles and order counts on the calendar** stay orders-only. A scanned paper carries no bottle total here, and guessing one would be a fabricated figure.
5. **Currency default (r38 concern).** Not built, because it is moot: intake writes `parsed.currency || null`, and `invoice-currency.ts` rule 1 reads no printed currency as the house's money.
