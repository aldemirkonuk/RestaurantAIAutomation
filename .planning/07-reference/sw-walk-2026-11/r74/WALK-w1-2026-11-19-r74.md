## Findings

Unit tests that read the CSS source cannot see it; only computed style on a production build does. Fix brief: a guard that fails any new bare-class rule whose property is also set by a `.mdv-*` shared rule, or at least a check list item "walk computed value".
2. /login has no H1 (H2 "Welcome back."). Fix brief: make it the H1 (the page turn names the first H1).
3. /reports CLS 0.115 from the shell header row (mdv-hdr__right/search) and the grid layout settling.
