## Calls (the session's, under the 2026-11-07 /goal)

1. **Gap 1 desk half: say only the "none counted" state.** Rejected:
   - "N not counted yet" on any partly counted list. Cocktail goods carried from the menu can never be counted, so that line would never go away.
   - A web-only inference from `totalBottles === 0 && lowStock === 0`. A counted good at 0 with a minimum of 0 would look the same, and the fact would differ from `next_steps.goods_counted`.
2. **Cocktails are left out of `goodsNotCounted`.** A mixed drink is not shelved; this is a partial answer to gap 7 on the desk only.
3. **Gap 6: say it in three places; never apply a default money.** The three places are /house, the money choice and the next steps. ADR 0117 Q25 and CurrencySection both say "the default is offered, never applied". Each sentence names both conditions ("names none", "no order"), so it claims no more than `filingCurrency` does.
4. **`money_set` is a next step, not a setup step.** It never decides `completed_at` or the "N/4" count (#1491 `SETUP_STEPS`). It has its own settled read, so a money failure never fails the setup read.
5. **Gap 14 not built.** Only owner paths link to /house (GetStarted:388, HouseMenu:324), so staff reach it only by typing the URL. `requiredRole` would show the stark "Access Denied" card. The r36 Sonnet brief stands unchanged.
