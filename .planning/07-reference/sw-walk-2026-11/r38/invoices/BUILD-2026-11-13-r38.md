## The session's calls (each recorded in its PR body)

- **R1, which lots the read counts.** It counts sold-out opening lots too, because `state_opening_lot_cost` restates empty lots and settles their draws. Rejected: `qty > 0`, which would hide the cost of stock already sold.
- **R1, the write surface.** The write sits in a sealed Sheet with HoldToApprove, opened by a button. Rejected: an inline field in the dropdown, which breaks ADR 0112 F8/F10.
- **R1, units and number format.** The cost is typed as shown (a kg, a litre, a bottle) and sent per the good's own unit. A lone mark followed by exactly 3 digits is refused as ambiguous (1.250 vs 1,250).
- **R2, order of named goods.** Goods are named alphabetically, capped at 8 with the rest counted. Rejected: ranking by uncosted quantity, which compares grams with bottles.
- **R2, display.** A note with links to `/inventory?open=<id>`. Rejected: a new register.
- **R3, a delivery's day.** It is `delivered_at`, else `verified_at`. Rejected: the invoice date, which is often missing on scans.
- **R3, a delivery with no invoice total.** It withholds the figure with a reason. Rejected: counting it as 0.
- **R3, a consolidated invoice.** It counts once, on the earliest delivery. Rejected: splitting it, because there is no line-to-delivery split.
