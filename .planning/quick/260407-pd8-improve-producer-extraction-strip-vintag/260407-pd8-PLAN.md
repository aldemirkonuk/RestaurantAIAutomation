# Quick Task 260407-pd8: Improve Producer Extraction

## Problem

Claude Vision sometimes conflates fields when parsing dense wine menus:
- `producer: "2022 bodegas y viñedos toledo"` — vintage year bleeds into producer
- `producer: "2022 domaine de justices loire valley spain"` — vintage + region + country all collapsed into producer

Both indicate Claude is unsure where one field ends and another begins.

## Solution

Two-layer fix:
1. **Prompt hardening** — explicit rules in `EXTRACTION_PROMPT` that forbid vintage in producer and region/country in producer
2. **Python post-processing normalizer** — deterministic cleanup applied to every wine after extraction, catches what the prompt misses

## Tasks

### Task 1 — Harden EXTRACTION_PROMPT rules for producer/vintage separation

**File:** `services/agent-orchestrator/services/claude_vision_extractor.py`

Add explicit bullet points to the extraction prompt:
- Producer MUST NOT start with a year
- Producer MUST NOT include region or country names
- If the printed text is "2022 Domaine X", vintage=2022, producer="Domaine X"
- Region/country go in their own fields, never in producer
