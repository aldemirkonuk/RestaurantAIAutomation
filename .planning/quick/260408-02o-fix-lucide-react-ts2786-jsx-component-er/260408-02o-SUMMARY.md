# Quick Task 260408-02o: Summary

**Task:** fix lucide-react TS2786 JSX component errors across codebase  
**Date:** 2026-04-08  
**Status:** Complete

## What Was Done

Fixed 1849 `TS2786: 'X' cannot be used as a JSX component` errors that affected the entire `apps/web` codebase.

**Root cause diagnosed:** Two-version type bleed in the pnpm workspace:
- `react-router-dom@6.30.3` (resolved from `^6.21.1`) peers with `react@18.3.1`
- `@types/react@18.3.27` was installed in the root pnpm store for those peer packages
- When TypeScript compiled `apps/web`, it resolved `React.ReactElement` in react-router's types using the root-store `@types/react@18.3.27`
- `@types/react@18.3` changed `ReactNode` strictness: `ReactElement<unknown, ...>` is no longer assignable to `ReactNode`
- This caused cascading TS2786 errors across all 133 TSX files using JSX components (including lucide-react icons, framer-motion, react-router routes)

**Fixes applied:**
1. `package.json` (root) — added `pnpm.overrides` forcing `typescript: "5.3.3"` and `@types/react: "18.2.47"` / `@types/react-dom: "18.2.18"` workspace-wide
2. `apps/web/package.json` — pinned `@types/react` to exact `18.2.47` and `@types/react-dom` to `18.2.18`
3. `apps/web/tsconfig.json` — reverted temporary `strictFunctionTypes: false` (no longer needed)
