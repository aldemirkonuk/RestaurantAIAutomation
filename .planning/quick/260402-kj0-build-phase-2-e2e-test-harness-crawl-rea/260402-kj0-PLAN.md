Self-contained async script. Set sys.path at module top:

```python
import sys

```

Then implement these functions (in order):

**SCORED_FIELDS constant:**
```python
SCORED_FIELDS = ["wine_name", "vintage", "region", "price_bottle", "country", "grape_variety"]
```
The crawled JSONL uses "price" not "price_bottle" — normalise during scoring by mapping `wine.get("price")` into `price_bottle`.

**score_completeness(wines: list) -> float:**
For each wine in wines, for each field in SCORED_FIELDS:
- For `price_bottle`: check `wine.get("price")` (the actual key in JSONL)
- For others: check `wine.get(field)`
- A value is "present" if it is not None, not "", and not 0
Return `present_count / (len(wines) * len(SCORED_FIELDS))`. Return 0.0 for empty list.

**validate_schema(wine: dict) -> list[str]:**
Returns list of violation strings. Required keys: `wine_name`, `source_type`, `source_url`, `restaurant_name`, `crawled_at`. Add a violation string for each missing or empty key.

**find_jsonl_for_restaurant(restaurant_name: str, menus_dir: Path) -> list[Path]:**
Slug the name: `re.sub(r"[^\w]", "_", restaurant_name.lower())[:50]`
Return all `.jsonl` files in menus_dir whose stem contains the slug as a substring. Return [] if menus_dir does not exist.

**read_jsonl(paths: list) -> list:**
Open each path, parse each non-empty line as JSON, collect into flat list. Skip malformed lines with a warning print.

**async run_crawl(restaurants: list, pass_threshold: float, output_path: Path):**
1. Check `os.environ.get("GOOGLE_API_KEY")`. If missing, run dry-run mode (see Task 2).
2. Import `WebCrawlerService` from `services.web_crawler`. Instantiate with `supabase_client=None` (dedup fail-open — all wines written, dedup test will compare counts after 2nd crawl instead).
3. For each restaurant dict `{"name": ..., "url": ...}`:
   a. Record JSONL count before crawl: count_before = len(read_jsonl(find_jsonl_for_restaurant(name, MENUS_DIR)))
   b. `result1 = await crawler.crawl_restaurant(url, name)`
   c. count_after_1 = len(read_jsonl(find_jsonl_for_restaurant(name, MENUS_DIR)))
   d. wines_extracted = count_after_1 - count_before
   e. Read those new wine dicts for scoring and schema validation
   f. completeness = score_completeness(new_wines)
   g. violations = [v for w in new_wines for v in validate_schema(w)]
   h. **Dedup test:** `result2 = await crawler.crawl_restaurant(url, name)` again
      count_after_2 = len(read_jsonl(find_jsonl_for_restaurant(name, MENUS_DIR)))
      dedup_pass = (count_after_2 == count_after_1)
      NOTE: with supabase_client=None dedup is fail-open and wines WILL be written again.
      To test real dedup without Supabase: check content_hash equality between result1 and result2.
      If result1.content_hash == result2.content_hash and result1.content_hash != "": dedup_pass = True (same page, real dedup would have blocked). If hashes differ: mark dedup_pass = True (different content, re-crawl is legitimate). Only mark dedup_pass = False if count_after_2 > count_after_1 AND result1.content_hash == result2.content_hash AND result1.content_hash != "".
   i. Build result dict:
      ```python
      {
          "name": name,
          "url": url,
          "content_type": str(result1.content_type),
          "crawl_error": result1.error,
          "wines_extracted": wines_extracted,
          "completeness_pct": completeness,
          "completeness_pass": completeness >= pass_threshold,
          "dedup_pass": dedup_pass,
          "schema_violations": violations[:10],  # cap at 10 for report
          "sample_wines": new_wines[:3],
      }
      ```
4. Call `write_report(results, pass_threshold, output_path)`.
5. Compute aggregate: restaurants_with_wines = [r for r in results if r["wines_extracted"] > 0], aggregate_completeness = mean of their completeness_pct (or 0.0 if none). dedup_failures = sum(1 for r in results if not r["dedup_pass"]).
6. Overall pass = aggregate_completeness >= pass_threshold and dedup_failures == 0.
7. Print:
   ```
   E2E complete. Report: {output_path}
   Overall: PASS  (or FAIL)
   ```
   If not passing, also print the specific reason.

**write_report(results: list, pass_threshold: float, output_path: Path):**
Write REPORT.md with:
- H1: "Phase 2 E2E Crawl Report" + ISO timestamp
- Pass threshold line
- H2 "Summary" — markdown table: Restaurant | Wines | Completeness | Dedup | Schema Violations | Result
  - Completeness formatted as "82.3%"
  - Result is "PASS" or "FAIL" or "NO MENU" (if wines_extracted == 0)
- H2 "Overall" — aggregate completeness %, dedup failure count, schema violation count, final PASS/FAIL
- H2 "Per-Restaurant Detail" — for each restaurant with wines > 0: restaurant name as H3, sample wines as markdown table (columns: wine_name, vintage, region, country, price, grape_variety)

**main():**
```python
import argparse, asyncio, os
def main():
    parser = argparse.ArgumentParser(description="Phase 2 E2E crawl harness")
    parser.add_argument("--config", default=str(PROJECT_ROOT / "scripts" / "e2e_restaurants.json"))
    parser.add_argument("--output", default=str(PROJECT_ROOT / "REPORT.md"))
    parser.add_argument("--pass-threshold", type=float, default=0.80)
    args = parser.parse_args()
    restaurants = json.loads(Path(args.config).read_text())
    asyncio.run(run_crawl(restaurants, args.pass_threshold, Path(args.output)))

if __name__ == "__main__":
    main()
```
