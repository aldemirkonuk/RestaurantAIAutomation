**Frontend mapper — `apps/web/src/lib/wine-format-mapper.ts`:**

Create a new file with a `mapWineRecordToMasterLibrary(record: WineRecord)` function that returns a plain object matching the `master_wine_library` insert shape:

```
{
  name: record.wine_name,
  producer: record.producer,
  vintage: record.vintage ? parseInt(record.vintage, 10) || null : null,
  price: record.price_bottle ? parseFloat(record.price_bottle) || 0 : 0,
  price_glass: record.price_glass ? parseFloat(record.price_glass) || null : null,
  region: record.region,
  country: record.country,
  grape_variety: record.grape_variety,
  primary_type: record.primary_type || record.color,
  color: record.color,
  sweetness_level: record.sweetness_level,
  tasting_notes: record.tasting_notes,
  description: record.description,
  bottle_size_ml: 750,  // default; Studio doesn't capture this yet
  source: 'studio_promotion',
}
```

Also export a `canPromote(record: WineRecord): boolean` function that returns true if `record.wine_name` is non-null and non-empty (minimum data for promotion).

This file is a frontend utility for preview/validation. The actual DB insert uses backend field mapping.

**Backend promotion endpoint — `services/agent-orchestrator/api/studio_routes.py`:**

Add a new Pydantic model `PromoteRequest` with field `submission_id: str`.

Add a new endpoint:
```python
@studio_router.post("/promote")
def promote_to_library(
    body: PromoteRequest,
    user: dict = Depends(require_studio_role("developer", "review_admin")),
):
```

Logic:
1. Fetch the submission from `master_wine_library_submissions` by `body.submission_id` using `.maybe_single()`.
2. If not found, return 404.
3. Extract field values. If `field_confidence` JSONB exists, prefer values from it (taking `.value` from each field entry). Otherwise fall back to top-level columns.
4. Build the `master_wine_library` insert payload with proper field mapping:
   - `name` ← `wine_name` from field_confidence or submission
   - `producer` ← `producer`
   - `vintage` ← parse int from `vintage` string
   - `price` ← parse float from `price_bottle`
   - `price_glass` ← parse float from `price_glass`
   - `region`, `country`, `grape_variety`, `primary_type`, `color`, `sweetness_level`, `tasting_notes`, `description` ← direct mapping
   - `bottle_size_ml` ← 750 default
   - `source` ← `"studio_promotion"`
   - `promoted_by` ← `user["sub"]`
   - `promoted_at` ← `datetime.utcnow().isoformat()`
   - `submission_id` ← `body.submission_id` (traceability back to original submission)
5. Check for duplicate in `master_wine_library` by name + vintage + producer (case-insensitive). If exists, return 409 Conflict with the existing wine ID.
6. Insert into `master_wine_library`. Return `{ "status": "promoted", "wine_id": new_id, "name": name }`.
7. Update the submission row: set `promoted_to_library = true` (add column if not present — use a simple try/except, if column doesn't exist the update just won't set it).

Per D-09, this lives in studio_routes.py. Per D-06, only developer/review_admin can promote.
