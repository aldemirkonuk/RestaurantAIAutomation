  <action>
Create `datasets/scripts/train_model.py`. The script must:

1. Resolve paths correctly. ultralytics resolves `path: wine_menus` in data.yaml
   relative to the directory containing data.yaml, NOT relative to cwd.
   Set cwd to the project root before calling model.train() so ultralytics can
   find the dataset. Use os.chdir() or pass an absolute path for the `data=`
   argument. Prefer absolute path to avoid cwd ambiguity:

   ```python
   import os, json
   from pathlib import Path
   from ultralytics import YOLO

   PROJECT_ROOT = Path(__file__).resolve().parents[1]   # Restaurant AI Automation/
   DATA_YAML    = PROJECT_ROOT / "datasets/wine_menus/data.yaml"
   RUNS_DIR     = PROJECT_ROOT / "datasets/wine_menus/runs"
   ```

2. Define training hyperparameters in a dict (so they can be serialised):

   ```python
   TRAIN_CONFIG = {
       "model":    "yolov8s.pt",
       "data":     str(DATA_YAML),
       "epochs":   100,
       "imgsz":    640,
       "batch":    8,
       "device":   "cpu",
       "project":  str(RUNS_DIR),
       "name":     "train",
       "exist_ok": True,
       # DATA-05 augmentation (per dataset_stats.json)
       "fliplr":   0.5,
       "degrees":  10,
       "hsv_v":    0.4,
       "mosaic":   1.0,
       # class loss weight — helps rare classes like section_header
       "cls":      0.5,
   }
   ```

3. Download/load base model, run training, save config:

   ```python
   model = YOLO(TRAIN_CONFIG["model"])

   train_args = {k: v for k, v in TRAIN_CONFIG.items() if k != "model"}
   results = model.train(**train_args)

   # Save config alongside best.pt for reproducibility (YOLO-05)
   config_path = RUNS_DIR / "train" / "training_config.json"
   config_path.parent.mkdir(parents=True, exist_ok=True)
   with open(config_path, "w") as f:
       json.dump(TRAIN_CONFIG, f, indent=2)

   print(f"Training complete. Best weights: {RUNS_DIR}/train/best.pt")
   print(f"Config saved: {config_path}")
   ```

4. Add a `if __name__ == "__main__":` guard so the script is importable.

5. Add a brief comment at the top documenting the AT RISK constraint:
   `# NOTE: section_header has 16 train / 0 val instances. mAP50 >= 0.90 is AT RISK.`

Do NOT add argparse, click, or any CLI argument framework — the hyperparameters
are hardcoded per TRAIN_CONFIG for reproducibility. The script is meant to be
run once with `python datasets/scripts/train_model.py`.
