```python
import time, json
from pathlib import Path
from ultralytics import YOLO

PROJECT_ROOT = Path(__file__).resolve().parents[1]
DATA_YAML    = PROJECT_ROOT / "datasets/wine_menus/data.yaml"
RUNS_DIR     = PROJECT_ROOT / "datasets/wine_menus/runs"
BEST_PT      = RUNS_DIR / "train" / "weights" / "best.pt"
REPORT_PATH  = RUNS_DIR / "train" / "eval_report.md"

CLASS_NAMES = [
    "wine_entry", "section_header", "wine_name", "producer", "vintage",
    "price", "grape_variety", "origin_info", "description", "serving_type",
    "rating", "classification", "bottle_info",
]
NC = 13
TARGET_WINE_ENTRY_MAP50    = 0.95
TARGET_SECTION_HEADER_MAP50 = 0.90
TARGET_INFERENCE_S         = 5.0
```

**Section A — Val-set evaluation (all classes):**

```python
model = YOLO(str(BEST_PT))
val_results = model.val(
    data=str(DATA_YAML),
    split="val",
    device="cpu",
    verbose=False,
)
# results.box.maps is a numpy array of per-class mAP50, length 13
# It may be shorter if some classes have no val instances — guard for this.
val_maps = list(val_results.box.maps) if val_results.box.maps is not None else []
# Pad to 13 elements with None if ultralytics returns fewer
while len(val_maps) < NC:
    val_maps.append(None)
```

**Section B — Test-set evaluation for section_header:**

Run a second val() call with split="test" to get section_header mAP from the
3 test instances. Extract index 1 (section_header) from test_results.box.maps.

```python
test_results = model.val(
    data=str(DATA_YAML),
    split="test",
    device="cpu",
    verbose=False,
)
test_maps = list(test_results.box.maps) if test_results.box.maps is not None else []
while len(test_maps) < NC:
    test_maps.append(None)
section_header_test_map50 = test_maps[1]  # may still be None if 3 instances insufficient
```

**Section C — CPU inference timing:**

Use a synthetic image at the typical full-menu resolution (2352x1076) to match
the YOLO-04 target. Do NOT use a test image from the dataset (avoid data leakage
in timing). Create a numpy zeros array of that size.

```python
import numpy as np
dummy_img = np.zeros((1076, 2352, 3), dtype=np.uint8)

# Warm-up run (ultralytics loads model lazily on first predict)
_ = model.predict(source=dummy_img, device="cpu", verbose=False)

# Timed run
t0 = time.perf_counter()
_ = model.predict(source=dummy_img, device="cpu", verbose=False)
inference_s = time.perf_counter() - t0
```

**Section D — Write eval_report.md:**

Write a Markdown file with these sections in order:

1. Header: `# Phase 2 Evaluation Report — YOLOv8s Wine Menu Model`
2. Generated date/time (datetime.now().isoformat())
3. Model path (relative from project root)
4. Training config summary (read from training_config.json — epochs, imgsz, batch, device)

5. **Per-Class mAP50 Table (Val Set)** — markdown table, 13 rows:
   | Class | ID | Val mAP50 | Note |
   |-------|----|-----------|------|
   | wine_entry | 0 | {val_maps[0]:.4f} | |
   | section_header | 1 | N/A (0 val instances) | See test-set below |
   | ... | | | |
   Show "N/A" for section_header val mAP — do not show a zero or blank.

6. **Key Targets — Val Set:**
   | Target | Value | Threshold | Status |
   |--------|-------|-----------|--------|
   | wine_entry mAP50 | {val_maps[0]:.4f} | ≥ 0.95 | PASS/FAIL |

7. **Section Header — Test Set (AT RISK):**
   - State the imbalance: 16 train / 0 val / 3 test instances, 125:1 ratio
   - Show test-set mAP50 for section_header (index 1 from test_maps)
   - Mark PASS / FAIL / INSUFFICIENT DATA as appropriate:
     - If section_header_test_map50 is None or test has <3 instances: "INSUFFICIENT DATA — 3 test instances; mAP unreliable"
     - If value >= 0.90: "PASS (test set)"
     - If value < 0.90: "FAIL (test set) — AT RISK (expected given 16 training instances)"
   - Explain why val mAP is not reported for this class

8. **CPU Inference Time:**
   | Image Size | Inference Time | Threshold | Status |
   |------------|----------------|-----------|--------|
   | 2352×1076 (dummy) | {inference_s:.2f}s | < 5.0s | PASS/FAIL |

9. **Overall mAP50 / mAP50-95** (val set): two values from results.box.map50 and results.box.map

10. **Recommendations** (brief, 3-5 bullets):
    - If wine_entry FAIL: suggest more epochs or lower learning rate
    - If section_header FAIL/INSUFFICIENT: suggest collecting more section_header images
    - If inference FAIL: suggest switching to yolov8n or reducing imgsz

Format all floats to 4 decimal places. Use `---` horizontal rules between sections.
