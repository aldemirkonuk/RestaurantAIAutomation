# Plan 04: Dockerfile + Railway Deployment Configuration

Wave: 2
Dependencies: 22-01 (requirements.prod.txt must exist)

## Goal

Create a production-ready Dockerfile for the agent-orchestrator service using `requirements.prod.txt`, with Railway-compatible `$PORT` binding, plus a `.dockerignore` to exclude dev artifacts, datasets, and ML model weights from the image.

## Context

- `services/agent-orchestrator/Dockerfile` does NOT exist yet
- Railway injects a `$PORT` env var at runtime — the uvicorn CMD MUST use `${PORT:-8000}` via shell form; hardcoding `--port 8000` causes container startup failure on Railway
- `requirements.prod.txt` created in Plan 22-01 excludes ~2 GB of ML deps (torch, surya-ocr, opencv, etc.) — Dockerfile uses this file, NOT `requirements.txt`, to keep image lean and build under Railway's 30-min timeout
- System packages needed: `libpq-dev` (psycopg2-binary), `libssl-dev`/`libffi-dev` (cryptography), `libglib2.0-0`/`libxrender-dev`/`libgomp1` (weasyprint PDF generation)
- `.dockerignore` must exclude `datasets/`, `*.pt` (YOLO model weights, can be 100+ MB), `tests/`, `.env`
- Railway deployment uses GitHub auto-deploy on push to `main` — Dockerfile path is configured in Railway dashboard pointing to `services/agent-orchestrator/Dockerfile`
- No `railway.toml` is needed since Railway auto-detects the Dockerfile and uses `$PORT`

## Tasks

### Task 1: Create Dockerfile

**File**: `services/agent-orchestrator/Dockerfile`
**Action**: create

**Details** — write this exact file:
```dockerfile
FROM python:3.11-slim

WORKDIR /app

# System dependencies:
# - build-essential, libpq-dev: required for psycopg2-binary compilation
# - libssl-dev, libffi-dev: required for cryptography package
# - libglib2.0-0, libsm6, libxext6, libxrender-dev: required for weasyprint PDF
# - libgomp1: required for some numpy/scipy operations
RUN apt-get update && apt-get install -y \
    build-essential \
    libpq-dev \
    libssl-dev \
    libffi-dev \
    libglib2.0-0 \
    libsm6 \
    libxext6 \
    libxrender-dev \
    libgomp1 \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies first (cached layer — only invalidated when requirements change)
COPY requirements.prod.txt .
RUN pip install --no-cache-dir -r requirements.prod.txt

# Copy application code
COPY . .

EXPOSE 8000

# Railway injects $PORT — shell form required for variable expansion.
# Default 8000 for local `docker run` without -e PORT.
CMD ["sh", "-c", "uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000}"]
```
