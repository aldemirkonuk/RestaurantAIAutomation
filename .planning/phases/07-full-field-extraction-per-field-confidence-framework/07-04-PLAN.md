3. Rewrite `get_review_queue()` (per D-13):
```python
@router.get("/review-queue")
def get_review_queue(limit: int = 50, offset: int = 0):
    """
    GET /api/v1/quality/review-queue
    Returns field-level review items grouped by wine submission.
    Only fields with status='pending' in field_review_queue are returned.
    """
    supabase = _get_supabase()
    if not supabase:
        raise HTTPException(status_code=503, detail="Database not available")

    try:
        # Query pending field reviews with submission context
        resp = (
            supabase.table("field_review_queue")
            .select("id, submission_id, field_name, current_value, confidence, source, status, created_at")
            .eq("status", "pending")
            .order("confidence", desc=False)  # lowest confidence first
            .range(offset, offset + limit * 5 - 1)  # fetch more rows since we group
            .execute()
        )
    except Exception as exc:
        logger.error("get_review_queue DB error: %s", exc)
        raise HTTPException(status_code=503, detail="Database query failed")

    rows = resp.data or []

    # Group by submission_id
    grouped = {}
    for row in rows:
        sid = row["submission_id"]
        if sid not in grouped:
            grouped[sid] = {"submission_id": sid, "pending_fields": []}
        grouped[sid]["pending_fields"].append({
            "review_id": row["id"],
            "field_name": row["field_name"],
            "current_value": row["current_value"],
            "confidence": float(row["confidence"]),
            "source": row["source"],
        })

    # Fetch wine context for each submission
    submission_ids = list(grouped.keys())
    if submission_ids:
        try:
            sub_resp = (
                supabase.table("master_wine_library_submissions")
                .select("id, payload, field_confidence, auto_blocked, restaurant_id")
                .in_("id", submission_ids)
                .execute()
            )
            for sub in (sub_resp.data or []):
                sid = sub["id"]
                if sid in grouped:
                    payload = sub.get("payload") or {}
                    grouped[sid]["wine_name"] = payload.get("wine_name")
                    grouped[sid]["vintage"] = payload.get("vintage")
                    grouped[sid]["restaurant_id"] = sub.get("restaurant_id")
                    grouped[sid]["auto_blocked"] = sub.get("auto_blocked", False)
        except Exception as exc:
            logger.warning("Failed to fetch submission context: %s", exc)

    items = list(grouped.values())[:limit]

    return {
        "total": len(items),
        "offset": offset,
        "limit": limit,
        "items": items,
    }
```

Update `ReviewQueuePatchRequest` model to use dict-based corrections per D-14:
```python
class ReviewQueuePatchRequest(BaseModel):
    corrections: Dict[str, Any] = {}  # field_name -> corrected_value
    approvals: List[str] = []  # field_names approved without change
    corrected_by: Optional[str] = None
```

PATCH implementation:
a) Fetch submission + field_confidence
b) For each correction in body.corrections:
   - Log to field_corrections table (original_value from field_confidence, corrected_value from request)
   - Update field_confidence JSONB: set new value, confidence=1.0, source="human_corrected"
   - Update field_review_queue row: status="corrected", reviewer, reviewed_at
c) For each approval in body.approvals:
   - Update field_review_queue row: status="approved", reviewer, reviewed_at
d) Write updated field_confidence back to submission
e) Check if any pending fields remain — if none, derive needs_review=False
f) Recompute auto_blocked via should_auto_block(fc)
g) If not auto_blocked and no pending fields: promote to master_wine_library with full field mapping
