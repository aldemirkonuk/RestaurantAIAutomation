**Step A — Add `useAssignWineToLocation` mutation to `useStorageLocations.ts`:**

At the bottom of `useStorageLocations.ts`, add a new exported hook (do NOT modify the existing `useStorageLocations` hook or `assignWineToLocation` function — they still handle optimistic cache updates):

```typescript
export function useAssignWineToLocation() {
  const { activeRestaurantId } = useAuth()
  const queryClient = useQueryClient()
  const restaurantId = activeRestaurantId ?? ''

  const assignMutation = useMutation({
    mutationFn: async ({ wineId, locationId, quantity }: { wineId: string; locationId: string; quantity: number }) => {
      const { data } = await apiClient.post(
        `/storage-locations/${restaurantId}/mappings`,
        { wineId, locationId, quantity },
      )
      return data
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: [MAPPINGS_KEY, restaurantId] })
      queryClient.invalidateQueries({ queryKey: [LOCATIONS_KEY, restaurantId] })
      queryClient.invalidateQueries({ queryKey: [WINES_AT_LOCATION_KEY, restaurantId] })
    },
  })

  const removeMutation = useMutation({
    mutationFn: async (wineId: string) => {
      const { data } = await apiClient.delete(
        `/storage-locations/${restaurantId}/mappings/${wineId}`,
      )
      return data
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: [MAPPINGS_KEY, restaurantId] })
      queryClient.invalidateQueries({ queryKey: [LOCATIONS_KEY, restaurantId] })
      queryClient.invalidateQueries({ queryKey: [WINES_AT_LOCATION_KEY, restaurantId] })
    },
  })

  return {
    assign: assignMutation.mutate,
    remove: removeMutation.mutate,
    isAssigning: assignMutation.isPending,
    isRemoving: removeMutation.isPending,
  }
}
```

Import `useMutation` from `@tanstack/react-query` at the top (it's already in the codebase — check the existing import line and add `useMutation` if not there).

**Step B — Create `LocationPickerCell.tsx`:**

Create a component that:
1. Receives `wineId: string`, `quantity: number`, and `compact?: boolean` props
2. Reads `locations` and `mappings` from `useStorageLocations()`
3. Derives current location: `const currentMapping = mappings.find(m => m.wineId === wineId)` → then `locations.find(l => l.id === currentMapping?.locationId)`
4. Uses `useAssignWineToLocation()` for mutations
5. Renders as a `<div>` with `position: relative`:
   - When closed: shows a `<button>` pill badge — if assigned, shows colored dot (location.color) + location.name; if unassigned, shows gray MapPin icon + "Assign location" text in muted style
   - When open (state `isOpen`): shows a dropdown `<div>` absolutely positioned below, with:
     - List of all locations: each shows colored dot + name + capacity info (`{currentCount}/{capacity}`)
     - For full locations (currentCount >= capacity): grayed out with "Full" badge, `disabled`
     - Currently selected location: checkmark icon
     - Separator then "Remove assignment" option (only if currently assigned)
   - Click outside closes the dropdown (use `useRef` + `useEffect` for click-outside detection)
6. On location select: calls `assign({ wineId, locationId: location.id, quantity })`, closes dropdown
7. On remove: calls `remove(wineId)`, closes dropdown
8. While `isAssigning` or `isRemoving`: show `Loader2` spinner instead of icon
