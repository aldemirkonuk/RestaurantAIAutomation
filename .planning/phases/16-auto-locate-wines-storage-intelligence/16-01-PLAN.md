<objective>
Fix the two root bugs blocking Phase 16 feature completeness:
1. **Cache invalidation bug:** After `assignWineToLocation` or `removeWineFromLocation`, the `[WINES_AT_LOCATION_KEY, restaurantId]` React Query cache is never invalidated — so `StorageLocationManager` always shows "No wines assigned" even after successful API persistence.
2. **Location filter dead code:** `selectedLocationFilter` appears in `filteredInventory`'s `useMemo` dependency array in `useInventoryPage.ts` (line 234) but is never used inside the filter body — so clicking a location chip has no effect on the table.

Purpose: Both bugs are foundational — the LocationPickerCell (Plan 02) and Auto-Locate (Plans 04–05) both depend on accurate cache state and correct filtering.

Output: Two modified files with targeted surgical fixes. No new files created.
</objective>
