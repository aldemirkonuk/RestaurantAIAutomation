Gap closure (from research_run_stats):
  null_rate_before = AVG(null_rate_before)
  null_rate_after  = AVG(null_rate_after)
  fields_filled_per_record = AVG(fields_filled) with percentile distribution
  time_to_fill     = PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY time_to_fill_hours)

Quality (joins research_run_stats + field_corrections + evidence_citations):
  promotion_rate   = SUM(fields_filled) / SUM(fields_targeted)
  human_override_rate = count of field_corrections where original value has evidence_citation
  conflict_rate    = SUM(fields_conflicted) / SUM(fields_targeted)
  source_tier_mix  = COUNT(*) GROUP BY source_tier from evidence_citations

Evidence hygiene (from evidence_citations):
  citation_completeness       = fraction with source_url != '' AND snippet != '' AND retrieved_at IS NOT NULL
  independent_corroboration_rate = fraction with corroboration_count >= 2 OR source_tier = 'A'
  fetch_verify_pass_rate      = fraction with fetch_verified = true

  attempts_per_filled_field    = SUM(attempts) / NULLIF(SUM(fields_filled), 0) from research_run_stats

Safety (from research_runs):

**GET /api/v1/research/metrics** — Returns all 5 metric categories.

Query strategy: Supabase does not support window functions via the REST API. Execute raw SQL via
`supabase.rpc("research_metrics_snapshot")` if an RPC function is available, OR fall back to
multiple targeted queries with Python-side aggregation. Use the fallback pattern (Python aggregation
from .execute() result sets) since no RPC function will be pre-created.

```
Response model ResearchMetricsResponse:
  gap_closure: dict  — null_rate_before, null_rate_after, fields_filled_p50, time_to_fill_p50_hours
  quality: dict      — promotion_rate, human_override_rate, conflict_rate, source_tier_mix (dict A/B/C %)
  evidence_hygiene: dict — citation_completeness, independent_corroboration_rate, fetch_verify_pass_rate
  throughput_cost: dict  — records_processed_per_day, cost_per_filled_field, attempts_per_filled_field
  safety: dict       — pii_policy_flags, regression_rate (always 0.0)
  computed_at: str   — ISO timestamp
```

Implementation:
1. Query research_run_stats for all rows: SELECT fields_targeted, fields_filled, fields_conflicted,
   null_rate_before, null_rate_after, time_to_fill_hours, attempts, cost_usd
2. Query evidence_citations for all rows: SELECT source_tier, fetch_verified, corroboration_count,
   source_url, snippet, retrieved_at
3. Query research_runs for aggregates: SELECT records_processed, cost_usd, pii_policy_flags, started_at
4. Query field_corrections WHERE corrected_by IS NOT NULL for human_override_rate numerator
   (join via submission_id to evidence_citations to find corrections of research-agent fills)
5. Python-side compute all ratios. Return as nested dict.

Handle empty tables gracefully: if no runs yet, return all zeros with computed_at.

---

**POST /api/v1/research/trigger** — Manually trigger a research run.

```
Request body: { submission_id: str | None, batch_size: int = 10 }
Response: { queued: int, run_message: str }
```

Two modes:
1. If submission_id provided: `research_agent_task.delay(submission_id)` — single record
2. If no submission_id: query master_wine_library_submissions for up to `batch_size` eligible
   records (last_research_run_at IS NULL OR last_research_run_at < NOW() - INTERVAL '7 days')
   filtered to those with any field_confidence entry below 0.8 for priority fields,
   then dispatch research_agent_task.delay(id) for each.

Return {queued: N} where N = number of tasks dispatched.

Wrap task dispatch in try/except — if Celery broker unavailable, return HTTP 503 with message.
Do not block on task completion — return immediately after dispatch.
