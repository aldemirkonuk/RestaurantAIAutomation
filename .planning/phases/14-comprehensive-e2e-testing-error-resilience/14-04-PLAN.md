**Fix the architectural gap — per D-05 from CONTEXT.md:**

In `services/agent-orchestrator/services/override_service.py`, add a new function `_maybe_promote_submission(supabase, submission_id)`:

1. Fetch submission: `select("id, payload, field_confidence, status, auto_blocked, restaurant_id, {jsonb_cols}")` from master_wine_library_submissions where id=submission_id
2. If submission status is not "pending_review" → return False (already decided)
3. Check remaining pending fields: `supabase.table("field_review_queue").select("id", count="exact").eq("submission_id", id).eq("status", "pending").execute()`
4. If remaining_pending > 0 → return False
5. Run `should_auto_block(fc)` — if blocked → return False
6. Build promotion row (mirror the exact mapping from quality_routes.py `patch_review_queue` — use `_fc_value` helper):
   - Map field_confidence fields to master_wine_library columns
   - Include JSONB enrichment columns from submission top-level
   - Set source="studio_approved", ai_enriched=True
7. Insert into master_wine_library
8. Update submission status to "approved"
9. Return True
10. Wrap entire function in try/except — promotion failure should log error but NOT crash the override response (non-fatal for the caller)

Import `_fc_value` from quality_routes.py or re-implement the 3-line helper locally:
```python
def _fc_value(fc, field_name):
    entry = fc.get(field_name)
    if not entry: return None
    return entry.get("value") if isinstance(entry, dict) else entry
```

Import `should_auto_block` and `JSONB_ENRICHMENT_KEYS` from `services.field_confidence`.

In `services/agent-orchestrator/api/studio_routes.py`, modify `submit_override()`:
- After `_apply_override_to_submission()` succeeds for auto_promoted path, call `_maybe_promote_submission(supabase, body.submission_id)`
- Import the new function from override_service

In `services/agent-orchestrator/api/studio_routes.py`, modify `decide_override()`:
- After `_apply_override_to_submission()` succeeds for approved path, call `_maybe_promote_submission(supabase, ov["submission_id"])`
