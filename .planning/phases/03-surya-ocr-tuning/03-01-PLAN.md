**Constants:**
```python
IMAGE_DIR = PROJECT_ROOT / "datasets" / "annotation_images"
OUTPUT_PATH = PROJECT_ROOT / "datasets" / "ocr_benchmark_results.json"
MODE = "baseline"  # overridable via CLI arg: sys.argv[1] if provided
```

**Image discovery:**
- `images = sorted(IMAGE_DIR.glob("*.png"))`
- Classify each: `source_type = "screenshot" if fname.startswith("Screenshot_") else "pdf_page"`

**OCR loop (NO preprocessing — raw PIL open only):**
```python
surya = SuryaOCRService()
results = []
for img_path in images:
    try:
        pil_img = Image.open(img_path).convert("RGB")
        text, conf = surya.read_image(pil_img)
        word_count = len(text.split()) if text else 0
        results.append({
            "filename": img_path.name,
            "source_type": source_type,
            "confidence": round(conf, 4),
            "word_count": word_count,
            "error": None
        })
    except Exception as e:
        results.append({
            "filename": img_path.name,
            "source_type": source_type,
            "confidence": 0.0,
            "word_count": 0,
            "error": str(e)
        })
    # Print progress every 10 images
    if len(results) % 10 == 0:
        print(f"  {len(results)}/{len(images)} processed...")
```

**Summary computation:**
- Group results by source_type
- For each group: count, avg_confidence (exclude error entries from avg), min, max
- Compute overall avg across all non-error entries

**Output JSON structure (write to OUTPUT_PATH):**
```json
{
  "generated": "YYYY-MM-DD",
  "mode": "baseline",
  "total_images": 334,
  "results": [...],
  "summary": {
    "screenshot": {"count": N, "avg_confidence": 0.XX, "min": 0.XX, "max": 0.XX},
    "pdf_page":   {"count": N, "avg_confidence": 0.XX, "min": 0.XX, "max": 0.XX},
    "overall":    {"count": 334, "avg_confidence": 0.XX}
  }
}
```
