# Phase 28 — Plan 02: Backend — Menu Import API + master_wine_library Bridge

## Objective
Build the NestJS `MenusModule` with a single unified `POST /menus/import` endpoint that accepts
three input methods (scan, CSV, manual), normalizes them into wine items, and feeds the results
into `menu_items`, `master_wine_library_submissions`, and `inventory`.

## Tasks

### Task 1: Normalized WineExtractItem type
```typescript
interface WineExtractItem {
  name: string              // required
  category?: string         // 'red', 'white', 'sparkling', 'rosé', 'dessert', 'other'
  vintage?: string          // '2019', '2020', etc.
  region?: string           // 'Burgundy', 'Napa Valley', etc.
  grape_variety?: string    // 'Pinot Noir', 'Chardonnay', etc.
  by_glass_price?: number
  bottle_price?: number
  raw_text?: string         // original text line from scan/csv
}
```

### Task 2: ScanParserService
`apps/api-gateway/src/menus/parsers/scan-parser.service.ts`

Takes a base64 image string, sends to the existing LLM client (Claude/Anthropic) with a prompt:
```
You are analyzing a restaurant wine list or beverage menu image.
Extract all wine and beverage items you can identify. For each item return JSON:
{ name, category, vintage, region, grape_variety, by_glass_price, bottle_price, raw_text }
Return an array. If a field is not visible, omit it.
```
Returns `WineExtractItem[]`.

Uses the existing `AgentOrchestrator` or `AnthropicService` pattern from other modules.
Fallback: if LLM call fails, throw `ServiceUnavailableException` — do not silently return empty array.

### Task 3: CsvParserService
`apps/api-gateway/src/menus/parsers/csv-parser.service.ts`

Parses CSV/Excel content (string input from frontend after FileReader).
Detects columns by header name (case-insensitive):
- name / wine_name / item
- vintage / year
- region / appellation
- grape / variety / grape_variety
- by_glass / glass_price
- bottle / bottle_price

Uses `papaparse` or simple manual parsing. Returns `WineExtractItem[]`.

### Task 4: MenusService.importMenu()
Orchestrates all three paths:

```typescript
async importMenu(dto: ImportMenuDto, restaurantId: string, userId: string) {
  // 1. Parse input → WineExtractItem[]
  let items: WineExtractItem[]
  if (dto.method === 'scan') items = await this.scanParser.parse(dto.data.imageBase64)
  else if (dto.method === 'csv') items = await this.csvParser.parse(dto.data.csvContent)
  else items = dto.data.items // manual

  // 2. Create or reuse restaurant_menus row
  const menu = await this.upsertMenu(restaurantId)

  // 3. Bulk insert into menu_items
  await this.supabase.from('menu_items').insert(
    items.map(item => ({ ...item, menu_id: menu.id, restaurant_id: restaurantId, source: dto.method }))
  )

  // 4. Submit to master_wine_library_submissions (fire-and-forget)
  this.submitToWineLibrary(items, restaurantId, menu.id).catch(err =>
    this.logger.warn(`wine library submission failed (non-fatal): ${err.message}`)
  )

  // 5. Add to inventory (source = 'menu_import', quantity = 0)
  this.addToInventory(items, restaurantId).catch(err =>
    this.logger.warn(`inventory seeding failed (non-fatal): ${err.message}`)
  )

  // 6. Mark onboarding progress
  await this.markMenuUploaded(userId)

  return { menuId: menu.id, itemsExtracted: items.length }
}
```
