# Phase 28 — Plan 03: Frontend — /get-started MenuImportOnboarding Page

## Objective
Build the new `/get-started` page that presents the three menu import methods in a polished,
distraction-free UI. This is the first screen new users see after email verification.

## Tasks

### Task 1: services/api/menus.ts
```typescript
export async function importMenu(method: 'scan' | 'csv' | 'manual', data: MenuImportData): Promise<MenuImportResult>
export async function getOnboardingProgress(): Promise<OnboardingProgress>
export async function updateOnboardingProgress(update: Partial<OnboardingProgress>): Promise<void>
```

### Task 2: GetStarted.tsx page layout

Full-screen layout with:
```
┌─────────────────────────────────────────────────────────────┐
│  🍷 WineOps                                          [logo] │
│                                                             │
│  Let's set up your wine list                               │
│  Uploading your menu helps WineOps understand what you     │
│  sell — making ordering, inventory, and AI suggestions     │
│  accurate from day one.                                    │
│                                                             │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │
│  │  📷 Scan     │  │  📄 Upload   │  │  ✏️ Manual   │     │
│  │  Photo       │  │  CSV/Excel   │  │  Entry       │     │
│  │              │  │              │  │              │     │
│  │ Take a photo │  │ Export from  │  │ Type your    │     │
│  │ of your menu │  │ POS or Excel │  │ wines in     │     │
│  │              │  │              │  │              │     │
│  │   [Start]    │  │   [Start]    │  │   [Start]    │     │
│  └──────────────┘  └──────────────┘  └──────────────┘     │
│                                                             │
│                  Skip for now →                            │
└─────────────────────────────────────────────────────────────┘
```

When a method card is activated, the other cards fade out and the selected card expands
to show its sub-component (scan/csv/manual).

### Task 3: MenuScanUpload sub-component
Reuses `CameraCapture` from `apps/web/src/components/scanner/CameraCapture.tsx`.
On image capture/upload:
1. Shows loading state: "Analyzing your menu with AI..."
2. Calls `importMenu('scan', { imageBase64 })`
3. On success: navigates to success screen
4. On error: shows inline error with retry button

### Task 4: MenuCsvUpload sub-component
- File input accepting `.csv`, `.xlsx`, `.xls`
- Uses `FileReader` to read as text
- Shows preview table of first 5 detected rows with column mapping
- "Import X wines" button → calls `importMenu('csv', { csvContent })`

### Task 5: MenuManualEntry sub-component
- Dynamic form rows: each row has Name, Vintage, Region, Price (glass/bottle)
- "Add another wine +" button appends a new row
- "Import X wines" button → calls `importMenu('manual', { items })`
- Minimum 1 row required (others optional)

### Task 6: Success screen
After any method succeeds:
```
✅ We found 42 wines on your menu!

Your wine list has been uploaded. WineOps will analyze and
enrich each wine in the background.

[View Your Inventory]   [Go to Dashboard →]
```

### Task 7: Register /get-started route in App.tsx
```tsx
<Route path="/get-started" element={<GetStarted />} />
```
Add to the public/semi-auth routes (alongside /verify-email).
