## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (`gap-1`), badge inner padding |
| sm | 8px | Row item spacing (`gap-2`), tight button padding |
| md | 16px | Default row padding (`px-4`), form field gaps |
| lg | 24px | Card section padding (`px-6 py-4`) — matches existing Settings card headers |
| xl | 32px | Between major sections (`space-y-4` in Settings = `gap-16px`; use `mt-8` for sub-section breaks) |
| 2xl | 48px | Empty state vertical padding (`py-12`) |
| 3xl | 64px | Full-page centered layout top margin |

Exceptions:
- Member row height: minimum 44px tap target (iOS HIG) — use `py-3 px-5` on rows
- Inline role dropdown trigger: minimum 44px wide touch target
- Avatar circle: 32px (`w-8 h-8`) — exception to the 4pt scale for visual weight

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` / `bg-slate-50` | Page background (`bg-slate-50`), card surfaces (`bg-white`) |
| Secondary (30%) | `#F7F8F9` / `bg-gray-50` | Row hover state (`hover:bg-gray-50/60`), section dividers (`border-gray-50`/`border-gray-100`), pending invite section bg |
| Accent (10%) | `#CD2D5B` (`wine-600`) | See reserved list below |
| Destructive | `#DC2626` (`rose-600`) | Remove member, revoke invite, leave restaurant — buttons, confirmation dialogs |
| Semantic info | `#2563EB` (`blue-600`) | Manager role badge bg/text |

Accent (`wine-600`) reserved for:
1. Primary CTA buttons ("Invite member", "Add [Restaurant]", "Confirm" in invite accept)
2. Active section tab indicator in Settings nav
3. Active branch indicator badge (`bg-wine-50 text-wine-600`)
4. Input focus ring (`focus:ring-wine-500`)
5. Role badge for `owner` role (`bg-wine-50 text-wine-600`)
6. Loading spinner in Settings page

Accent is **NOT** used for: hover states, secondary actions, informational copy, role badges for manager/staff.

Role badge color map:
- `owner` → `bg-wine-50 text-wine-600 ring-wine-100`
- `manager` → `bg-blue-50 text-blue-600 ring-blue-100`
- `staff` → `bg-gray-100 text-gray-600 ring-gray-200`

## Interaction Contracts

### Role Dropdown (Team Tab — Owner Only)

- **Trigger:** Click on role badge area (or an explicit chevron next to badge) — transforms badge into `<select>`
- **On change:** Immediate optimistic update → fire `PATCH /restaurants/:id/members/:userId` → on error: revert + `toast.error("Couldn't update [Name]'s role. Please try again.")`
- **No confirmation required** for role changes (per D-13)
- **Cannot demote self** if only owner: show last-owner inline block instead

### Member Removal Confirmation

- **Trigger:** Click trash icon on member row
- **Opens:** AlertDialog (Radix `@radix-ui/react-alert-dialog`)
- **Confirm:** `DELETE /restaurants/:id/members/:userId` → optimistic remove from list → success toast
- **Error:** Revert list state + `toast.error("Failed to remove [Name]. Please try again.")`

### Revoke Invite

- **Trigger:** Click "Revoke" on pending invite row
- **No confirmation dialog** — revoke is lightweight and reversible by generating a new invite
- **Immediate:** Optimistic removal from pending list → fire `DELETE /restaurants/:id/invites/:code`
- **Error:** Revert + `toast.error("Couldn't revoke invite. Please try again.")`

### Invite Accept (Logged-In)

- **Trigger:** Click "Add [Restaurant Name]" on `/invite/[code]`
- **Loading:** Button shows spinner + "Adding…"
- **Success:** Redirect to that restaurant's dashboard → `toast.success("You've joined [Restaurant Name]!")`
- **Error:** Show inline error below button (not a toast): `text-sm text-rose-500 mt-3 text-center` — copy: "Couldn't add you to [Restaurant Name]. Please try again or contact the owner."

### Branch Switch on No-Access Page

- **No forced logout** — user stays authenticated
- **If other branches exist:** Show branch switcher (reuse existing component)
- **If no other branches:** Show "Sign in to a different account" link → `/login`
- **Redirect timing:** Redirect to `/no-access?from=[restaurant_name]` immediately upon session-active detection of removal

All animations use Framer Motion `motion.div`. Reuse existing patterns from codebase.
