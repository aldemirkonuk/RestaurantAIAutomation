```typescript
async onModuleInit() {
  const clientId = this.configService.get<string>('GMAIL_CLIENT_ID');
  const clientSecret = this.configService.get<string>('GMAIL_CLIENT_SECRET');
  const refreshToken = this.configService.get<string>('GMAIL_REFRESH_TOKEN');
  this.senderEmail = this.configService.get<string>('GMAIL_SENDER_EMAIL') || 'notifications@wineops.ai';

  if (!clientId || !clientSecret || !refreshToken) {
    // Any of the three missing → mocked. No error thrown.
    this.logger.warn('Gmail credentials not configured. Email sending will be mocked.');
    return;
  }
  this.gmailCredentials = { clientId, clientSecret, refreshToken };
  this.logger.log('Gmail API deferred — will initialize on first send (fast startup).');
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Railway Variables → GmailService | OAuth2 credentials injected via env vars — readable only to Railway service |
| GmailService → gmail.com API | TLS-encrypted HTTPS — refresh token exchanged for short-lived access token |
| gmail.users.messages.send | Sends from wineops.ai@gmail.com — recipient is MANAGER_EMAIL (controlled) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-03-01 | Information Disclosure | GMAIL_REFRESH_TOKEN exposed in Railway logs | mitigate | GmailService logs credential NAME not VALUE (configService.get() result not logged); verified pattern in gmail.service.ts onModuleInit |
| T-23-03-02 | Spoofing | Compromised GMAIL_REFRESH_TOKEN → unauthorized email send from wineops.ai@gmail.com | mitigate | Token scoped to gmail.send + gmail.readonly only; revocation via Google Account → Security → Connected apps |
| T-23-03-03 | Information Disclosure | DEFAULT_RESTAURANT_ID UUID exposed | accept | UUID is a non-secret restaurant identifier; no sensitive data attached to knowing the UUID |
| T-23-03-04 | Tampering | Test email endpoint (@Public()) accessible without auth | accept | send-template endpoint triggers email only to addresses provided in request body; cannot inject SQL or access other data; acceptable for MVP |
</threat_model>
